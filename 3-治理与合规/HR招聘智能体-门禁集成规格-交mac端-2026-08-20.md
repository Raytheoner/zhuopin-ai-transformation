# HR·招聘智能体 门禁集成规格（交 mac 端）

> **为什么需要这份文件**：招聘智能体源码不在本仓库（mac 端独立项目），本项目的 CC 碰不到它。
> 这份规格把「照抄什么、改成什么、怎么验」写死，**你带回 mac 端照做即可**。

## 〇、当前状态与目标

| | 现状（实测） | 目标 |
|---|---|---|
| `GET /hr/recruit-agent/` | **200 匿名直接进** | **302 → `/_gate/login`** |
| `GET /docs`（Swagger UI） | **200 公开** | **302** |
| `GET /openapi.json` | **200 公开，暴露 3 个匿名 POST 的完整签名** | **302** |
| 3 个 POST 端点 | **匿名可调** | **401** |
| 其余五服务（8090/8091/8093/8094/8096） | 均 302 → 登录页 | —— |

🔴 **8095 是六个服务里唯一无门禁的** ——把它挂上门户导航等于主动引流到唯一不设防的入口，故必须先接门禁。

## 一、🔑 互认的原理（只有一条，先理解它再动手）

**HMAC 密钥就是口令本身，不存在第二个 secret。**

```
zp_gate cookie = "{过期时间戳}.{HMAC-SHA256(口令, str(过期时间戳)).hexdigest()}"
```

⇒ **跨服务互认的充要条件 ＝ 同一 host ＋ `.env` 里填同一个 `ZP_GATE_PASSWORD` 值。**
各服务**各自独立无状态校验**，无服务端 session、无中心鉴权服务。

**⇒ 所以「按其他部门的口令登入」天然成立**，不需要额外做任何对接——只要值填对。

## 二、必须做的 9 条（每条可独立验证）

### 1. 复制算法核心，**不要引入 `zhuopin_platform` 包**

从本仓库 `5-平台底座/zhuopin_platform/zhuopin_platform/shared_tools/simple_gate.py` 的 **L32-L104** 逐字复制这些进你项目的一个模块：

`COOKIE_NAME` / `LOGIN_PATH` / `LOGOUT_PATH` / `DEFAULT_COOKIE_DAYS` / `_sign` / `make_cookie_value` / `verify_cookie_value` / `verify_auth_token` / `parse_cookie_header` / `is_authorized` / `_safe_next`

🔴 **一个字符都不能改** —— 改了就不互认。这几个函数**只用 `hashlib` / `hmac` / `time` / `http.cookies`，零三方依赖**。

**为什么不带整个包过去**：① 该包的门禁**集成层是 Flask 专用**，拖进 FastAPI 项目是反向引入依赖；② **本项目已有同款先例并被明确认可** —— `1-转型规划/AI运营指挥中心/serve.py`（纯 `http.server`）L12-18 就写明「刻意不引入 `zhuopin_platform`、自包含复制、cookie 名/签名算法/登录路径与其完全一致」。
⚠️ **代价要知道**：这是第二份副本，须与 `simple_gate.py` 保持字面一致；`serve.py` 已经承担同一代价。

**验证**：本地用同一口令生成一个 cookie，拿本仓库的 `verify_cookie_value` 交叉校验通过。

### 2. 口令读环境变量 `ZP_GATE_PASSWORD`

来源 ＝ `.51` 上 `C:\apps\zhuopin-recruit-agent\.env`。加载写法照 `run_sc2.py:39-50`（自 `__file__` 向上逐级找最近的 `.env`，`os.environ.setdefault` 不覆盖已有）。

🔴 **HMAC 密钥就是这个口令值本身，不要另造 secret。**

### 3. 🔴 值必须与 `.51` 其余服务同值

现网五服务共用一个值。取值方式：**在 `.51` 上从既有 `.env`（如 `C:\sc2\.env`）直接读取复制，全程不回显、不落任何会被提交的文件。**

**验证**：浏览器先登录 8096，同一浏览器直接开 `http://192.168.100.51:8095/hr/recruit-agent/` —— **应免登录进入**。这是最关键的一条验收。

### 4. 中间件默认拒绝

```python
@app.middleware("http")
async def gate(request, call_next):
    # 取 Cookie 头与 X-Auth-Token，调 is_authorized(secret, cookie_header, auth_token)
    # 未通过：
    #   GET/HEAD  → 302 到 /_gate/login?next=<urlencode(path + query)>
    #   其余方法  → 401 text/plain（🔴 POST 不要 302）
```

🔴 **默认拒绝一切、只放行显式豁免清单** —— 这样 `/docs`、`/openapi.json`、`/redoc` **自动被罩住**，不用单独枚举（枚举法会漏）。

### 5. 🔴 口令为空时不装门禁，但部署后必须显式核对

对齐 `simple_gate.py` L155-157：**取值为空/未设置时原样返回、门禁完全不装**（保留本地开发直通）。

⚠️ **这是一个已知的静默失效形态**：不报错、不告警，服务照常起，只是**完全没有鉴权**。
⇒ **部署后必须显式核对该键非空**，不能只看"服务起来了"。

### 6. 自建 `/_gate/login`（GET + POST）与 `/_gate/logout`（GET）

🔴 **路径在根、不带 `/hr/recruit-agent` 前缀** —— 与其余五服务一致。
登录页可直接复用 `simple_gate.py` L106-141 的 `login_page_html`（纯字符串、无依赖）。
POST 表单字段名：`password` 与 `next`。校验用 `hmac.compare_digest`。

### 7. 🔴 签发 Cookie 的属性逐字对齐

```
zp_gate={值}; Path=/; Max-Age=2592000; HttpOnly; SameSite=Lax
```

- 🔴 **不得加 `Secure`** —— LAN 是明文 HTTP，加了 cookie **永不发送**。
- 🔴 **`Path` 必须是 `/`，不能写成 `/hr/recruit-agent`** —— 否则跨服务互认静默失效。

**这两处写错，门禁看起来能用，但第 3 条那个互认验收会失败，且不会有任何报错。**

### 8. 🔴 豁免清单：只放健康检查一条，且必须带全前缀

**判据是精确字符串相等**（`simple_gate.py` L165 `if request.path in exempt`）——**无前缀匹配、无尾斜杠容错**。

⇒ 若你的健康检查在 `/hr/recruit-agent/api/ping`，就必须**原样写这个全路径**；沿用缺省的裸 `/api/ping` 会**零命中**。

**SC2 踩过这个坑**（`sc2/webapp.py:59-62` 还留着当时的注释）：其路由全在 `/procurement/sc2` 之下，缺省豁免是裸 `/api/ping` ⇒ **没有任何路径命中豁免，健康检查与此后一切存活探测全被 302 到登录页，把一个好服务判成坏的。**

🔴 **`/docs`、`/openapi.json`、`/redoc` 绝不进豁免清单。**
`/_gate/login`、`/_gate/logout` 自动豁免。

⚠️ **豁免路径的具体值须按你实际路由确认，不要照抄本文的字面值** —— 我没有你的源码，不知道健康检查端点叫什么。

### 9. 部署侧

`.51` 上补 `.env` 键（**不回显值**）→ 重启 `ZhuopinRecruitAgent` 计划任务 → **核对进程 `CreationDate` 真的刷新了**（不只信脚本打印"已重启"，这是本项目 2026-07-14 的教训）。

## 三、验收判据

**匿名、无 Cookie、无 `X-Auth-Token`，且从笔记本外部而非 `.51` 本机发起**（本机测会漏掉防火墙与绑定地址问题）：

| 请求 | 应返回 |
|---|---|
| `GET /hr/recruit-agent/` | **302** → `/_gate/login?next=%2Fhr%2Frecruit-agent%2F` |
| `GET /docs` | **302** |
| `GET /openapi.json` | **302**（**当前是 200，这就是缺口本身**） |
| 3 个 POST 端点 | **401 `text/plain`**（🔴 不是 302） |
| `GET /hr/recruit-agent/api/ping`（或你实际的健康检查路径） | **200**（豁免生效） |
| `GET /_gate/login` | **200** 登录页 |
| `POST /_gate/login`（正确口令） | **302** ＋ `Set-Cookie: zp_gate=...; Path=/; HttpOnly; SameSite=Lax` |
| 任意端点带 `X-Auth-Token: <口令>` | **200**（程序化通道，供健康检查/脚本用） |
| 🔴 **浏览器先登 8096，再开 8095** | **200，免登录** —— **互认真验，最关键的一条** |
