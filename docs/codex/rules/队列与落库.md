# 队列、落库与接力

唯一日常管理入口为`工具-队列查询.py --digest --actionable`，一次联合查看、认领及去重；`[D:机/业]`仅为分类。正本仍是全景目录`跨桌任务队列-机制环境.md`与`跨桌任务队列-业务场景.md`，共一把锁；协议〇在队列顶部，机制治理另见`环境保障线.md`。

- 开工查询认领/触碰区，收工写状态/产出/下游追行；与他人在办重叠报总线不抢领，§三冻结即停。sweep从§二取活，当前未批提交须保持在办；旧CC兜底不再启用，任务由现行Codex workflow承接；落库不等于自动获准提交。
- 读侧K3：真身及归档禁通读/grep。判行用`工具-队列查询.py --row N --section 一|四 --field all`；开场`--digest --actionable`保留open/partial且非🛑，机器字段不明必须保留。全池才去掉actionable。
- 写侧：本机Windows PowerShell运行`工具-共享文档编辑锁.py`；acquire→多次edit-row→§二登记→release，各步立即核进程退出码，最后status反查。多行不要连发commit-edit；只读查询可两侧使用。
- 开启泳道看护后，原行已批且无冲突即由当前主会话认领、构建，不停在取证。第一笔实质写入前核原批准/当前唯一写方/精确触碰区，锁内用`handoff.py claim-slice --plan <Agent临时参数>`先完成§二预登记及原行绑定、回读，再release后实施。尚不存在的精确目标用既有`在办（预登记，收工时精确化）`状态；失败不得先造文件再补登记，普通登记校验不放宽。单项阻塞写原行后继续独立项，每次留步/收口前重查原池；读取器`execution_ready=false`不是新增冻结。
- 人工核清§一当前状态后，沿现有解析格式：机器字段之后以`【当前状态摘要】`开头，当前事实写在首段，`━━━`之后保留历史原文。仍待批准或核验的事项须写在当前首段；不得用历史已答掩盖新决策或真实未完闸。
- §一状态/§四事项≤4096B；超限先`工具-队列行K2外置.py --apply`迁`队列行日志/#N.md`，行内留首段/末段/指针，回写只追加末段。锁hook/行长门禁不替代实际acquire。
- release前每个脏文件须入§二或逐个点名`登记豁免：<路径>（作者/到期）`，禁泛豁免。孤儿代登先核`git diff --numstat`和实际diff，仅已核日志/留痕可代登。批次尾段用语义词，旧名不追改。
- 机制WIP上限22不改，可动余量先需求侧[D:机]、后环境；判据是减少人的速度环节。周一计划先queue-audit，gap须有主/截止/已派单。
- 谁端题谁收答，跨端转达标「已答，勿重做」及执行者；不两端重复答。旧泳道看护停点仍由原端出。待派发答复写队列并给回原session收口词，核产出推送、状态✅、§二落库、遗留升格；未获相应授权不能为凑四项擅自推送。
- 跨会话复命三源＝会话jsonl/队列/git log；冲突以队列和git为准，解析失败回退粘贴不猜。算法按需读`专线opener模板库.md`§〇.15；批次命名详见`opener骨架.md`编号脱形节。
- sweep第16类B清单只列、不合不删，交每周清扫；判据`工具-未并入分支分类.py`。无承接载体单列，不硬归因。
- `*-main-leak.patch`禁cat，走`工具-main-leak回放.py`；FAIL看文件名，不必读diff。试算用`--extra`，白名单取现行opener批处理v2，解析失败出声。
