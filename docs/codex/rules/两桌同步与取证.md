# 两桌同步、git与取证

Codex执行入口以根AGENTS为准；当前执行归现行Codex workflow；旧Cowork/CC仅作历史来源，不作为派发目标或恢复入口。commit不是桌面判据或自动授权；跨业务、真实源与生产的权限仍须明确授权、证据、逐文件diff和登记。旧「开启Opener」按已批task继续，不复活claude后台；取证推翻方案须回报改判。

## git
- 开工只读核分支、工作树、占用和未提交；同文件串行。不默认pull/commit/push；同步核授权、干净目标、无人占用，合入ff-only，不强切共享主仓。
- 必要时`git fsck --connectivity-only`；错误即停，按备份未提交→重clone→拷回gitignore件流程恢复，不能就地删现场。OneDrive平时关、每周手动备份。
- ff验收是零回归：纯master与候选同命令逐条对照；任何候选独有失败先停，不改断言/skip。实际授权仍逐项。零diff PR核`git log master..branch`为空后带说明关闭。
- 开/收工核上级`*AI转*`唯一；U+FFFD兄弟目录即停、隔离及逐文件哈希比对，禁直接删。`Claude outputs/`等交付副本不入库，原资产仍在正本。

## 取证
- 写日期当场`Get-Date -Format 'yyyy-MM-dd'`；引用时刻明示UTC/本地。本机UTC+8；企微audit与告警时间先按其实际UTC字段核，mtime/计划任务/事件日志为本地。知识库§一.2/一.3只在时序问题时读。
- 退出码独立调用后立即取`$LASTEXITCODE`，不取管道末端或cmd解析期旧变量。只读结果异常干净先核对象，写后反查；重启只认ID27 Kernel-Boot，判据本身也须质疑。
- 新鲜度敏感对象本机PowerShell全名cmdlet直读，不用挂载副本；状态页入口`zhuopin-project-status`。工具回退/文件变旧时分别定向读`0-学习与工具/取证方法知识库.md`§二/三.1，不整读50KB知识库。
- 「已修/转绿」给完整命令、真实回显/哈希；缺回显写未取证。门禁含多族判据时核整套，不能用一族冒充全绿；hook横幅不代替现时验证。
- 企微发送须该项授权；既有群工具`0-学习与工具/发企微.py`读取本地环境，不复制凭据。起草文档不等于已发，发送成功不等于收到回件。
- memory只作技巧检索，纪律正本仍是根AGENTS、rules与队列；会做错事的判据不得移入memory。当前端不继承旧Desktop/Cowork记忆为权威。
