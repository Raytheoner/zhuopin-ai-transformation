2. 开场包含按序的六项设置，派生显式 gpt-6-luna/high；不修改主会话模型。会话标识使用原生 source_id/thread_id 绑定，不调用旧 RPC、不改父任务标题。

5. 调用方真实提供的做什么/不做什么、输入引用、批次与心跳等约束必须保留；不能接受却丢弃。沿用收工实证和哨兵规则，不把进程退出 0 当业务验收。
6. 先定向验证，收敛后完成受影响项目完整 pytest 与功能/audit；失败保留证据，不用过滤或 skip 凑绿。不自动 commit/push、ff、部署或外发；ff 仅具体获准且前提满足时 ff-only。
7. 生成物通过原生自检后才在同一占号锁内声明编号。输入错误、自检失败、锁错误均不出件、不占号；不抢占或清理未知锁。
