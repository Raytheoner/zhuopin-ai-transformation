## MODIFIED Requirements

### Requirement: C01–C10 跨模块一致性校验

系统 SHALL 执行 C01–C10 共 10 项跨模块一致性校验，按工作汇总.xlsx「规则说明（开发）」§三定义取数与偏差处理，输出独立的"跨模块校验结果"段。

跨模块校验结果 MUST 走独立的结果列表（`cross_module_items`），**MUST NOT 并入 82 条规则的判定结果集**，因而 MUST NOT 影响总分与档位——扣分与一票否决仍只由「立项门禁」82 条规则决定。

每一条 C01–C10 MUST 显式携带其**实现状态**（已实现／未实现）。未实现的条目 MUST 写出**具体的未实现原因**，MUST NOT 以"扩容期补齐"一类笼统措辞代替；已实现的条目 MUST 给出两侧取数值与偏差。

与既有 82 条规则等价或近等价的条目（C01↔规则 14+68、C08↔规则 68、C04 止半边↔规则 66、C09↔规则 59、C10↔规则 60）MUST 在条目内标注所等价的规则编号及该规则的判定结果，使「立项门禁」表（精确相等＋重要级扣分）与「规则说明（开发）」§三（10% 容差＋警告）两套口径的差异在报告上可见，MUST NOT 静默采用其中一边而隐去另一边。

#### Scenario: 数值偏差类（C01/C02/C03/C08）
- **WHEN** 校验人员/开发成本/收入/预算工时跨模块一致性
- **THEN** 偏差 ≤10% → [通过];偏差 >10% → [警告]
- **AND** 条目内给出左右两侧取数值、绝对差与相对偏差百分比

#### Scenario: 数值类任一侧缺数
- **WHEN** C01/C02/C03/C08 的任一侧取不到数（表未解析或字段为空）
- **THEN** 判 [未实现/待人工核]（PENDING）并写明缺的是哪一侧，MUST NOT 将缺失侧按 0 参与计算

#### Scenario: 跨表量纲不统一
- **WHEN** 成本效益表以「元」计价而收入依据表以「万元」计价（`_cb_income_scale` 判定 scale=10000）
- **THEN** C02/C03 的成本效益侧取数 MUST 先按该 scale 换算为万元再比对
- **AND** C09/C10 因属同表内自洽公式（F/D、P/(D+J)），量纲自动约掉，MUST NOT 重复换算

#### Scenario: 时间一致性（C04）
- **WHEN** 校验模块一"开始日期"/"结束日期" 与 模块九首阶段开始/末阶段结束
- **THEN** 不一致 → [警告]
- **AND** 该条 MUST NOT 判为阻断——"止"半边已由规则 66（阻断级）覆盖并计入扣分，本段不重复否决

#### Scenario: 合规强关联类（C05/C06/C07/C09/C10）
- **WHEN** 校验风险-里程碑对应(C05)、ASIL-功能安全(C06:ASIL≠NA 但模块四无功能安全目标)、ISO21434-信息安全(C07)、收益自洽(C09 毛利率=F/D)、全生命周期毛利率(C10=P/(D+J))
- **THEN** 满足 → [通过];不满足 → [错误/阻断]
- **AND** 该阻断效力 MUST 由「立项门禁」82 条规则承载而非由跨模块段自行否决——C09/C10 经规则 59/60 承载（两者公式逐字相同，已计入扣分）；C05/C06/C07 的阻断效力待其判定口径裁定并实现时一并落到规则侧，在此之前 MUST 判未实现而不冒判
- **AND** C06/C07 因关联功能安全/信息安全合规,其判定结果一旦实现即须计入阻断项,影响总判定

#### Scenario: 收益自洽类复用既有规则（C09/C10）
- **WHEN** 校验收益自洽(C09 毛利率=F/D)、全生命周期毛利率(C10=P/(D+J))
- **THEN** 系统 MUST 复用规则 59/60 已产出的判定结果，MUST NOT 另行重算同一公式
- **AND** 条目证据内标注"复用规则 59/60 判定"
- **AND** 若本次判定结果集中不含规则 59/60，该条目判 PENDING 并写明原因，MUST NOT 静默跳过

#### Scenario: 合规强关联类暂缓实现（C05/C06/C07）
- **WHEN** 风险-里程碑对应(C05)、ASIL-功能安全(C06)、ISO21434-信息安全(C07) 的判定口径尚未由业务方裁定
- **THEN** 三条 MUST 判 [未实现]（PENDING）并各自写明具体阻塞原因（C05 两侧词汇体系不匹配、字面实现会把评审判合格的样本判成阻断错误；C06 需 ASIL"不适用"同义词表；C06/C07 需新增模块四"项目目标"解析）
- **AND** 在口径裁定前 MUST NOT 冒判——不得以任何猜测的匹配语义产出判定结果
