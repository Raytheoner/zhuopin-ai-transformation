## ADDED Requirements

### Requirement: 标准化风险评估报告生成
系统 SHALL 在评分计算完成后，自动生成 Markdown 格式的供应商风险评估报告文件。

报告文件命名规则：`{供应商名称}_{YYYYMMDD_HHMMSS}_风险评估报告.md`

报告必须包含以下节：
1. 报告头（供应商名称、评估日期、评估人、综合风险等级）
2. 综合评分摘要
3. 各维度评分明细
4. 核心风险描述（≤3 条，AI 生成）
5. 建议动作（≤3 条，AI 生成）
6. 数据来源说明
7. 审批确认区（采购经理签字位置）

#### Scenario: 报告正常生成
- **WHEN** 评分引擎完成所有维度计算
- **THEN** 系统生成完整报告文件并保存到 `reports/` 目录，控制台输出文件路径

#### Scenario: 报告目录不存在
- **WHEN** `reports/` 目录不存在
- **THEN** 系统自动创建该目录后生成报告，不报错退出

### Requirement: AI 生成核心风险描述
系统 SHALL 调用 Claude API，基于评分结果生成不超过 3 条核心风险描述，每条不超过 50 字。

AI 生成规则：
- 仅基于传入的评分数据和维度信息生成，不得超出输入范围推断
- 优先描述得分最低的维度的具体风险含义
- 使用中文，语言精简专业

#### Scenario: AI 文本生成成功
- **WHEN** 系统调用 Claude API 并返回有效文本
- **THEN** 报告中包含 1-3 条核心风险描述，每条前缀序号标注

#### Scenario: AI API 调用失败
- **WHEN** Claude API 返回错误或超时
- **THEN** 报告中核心风险描述填入占位文本"[AI 分析不可用 - 请采购经理手动填写]"，评分结果仍正常展示，不阻断报告生成

### Requirement: AI 生成建议动作
系统 SHALL 调用 Claude API，基于综合风险等级和各维度评分，生成不超过 3 条具体可执行的建议动作。

建议动作规则：
- 针对风险等级 4-5 级：建议包含"考虑启动替代供应商开发"
- 针对交付维度低分：建议包含"启动供应商绩效改善计划（SIP）"
- 针对 IQC 维度低分：建议包含"要求供应商提交质量整改报告"
- 1-2 级低风险供应商：建议以"维持现状"或"加入优选供应商清单"为主

#### Scenario: 建议动作生成
- **WHEN** AI 根据评分数据生成建议
- **THEN** 报告中包含 1-3 条建议动作，格式为编号列表

### Requirement: 数据来源透明度说明
系统 SHALL 在报告中明确标注每个维度数据的来源。

来源标注类型：
- `[SRM 自动]`：从携客云 SRM API 自动获取
- `[人工录入]`：操作人手动输入
- `[人工覆盖]`：SRM 数据被人工值覆盖
- `[数据不足]`：数据缺失，使用默认值
- `[ERP 待接入]`：该字段等待 ERP 接口接通后自动获取

#### Scenario: 混合数据来源报告
- **WHEN** 部分维度来自 SRM、部分来自人工录入
- **THEN** 每个维度评分行旁均显示对应来源标注

### Requirement: 采购经理审批确认区
系统 SHALL 在报告末尾包含标准化审批确认区，供采购经理打印签字或电子确认。

确认区内容：
- 声明文字：本报告为 AI 辅助生成的建议性意见，最终决策由采购经理确认。
- 签字行：采购经理姓名 / 签字 / 日期
- 确认结论选项：□ 接受评估结论  □ 有异议（请附说明）

#### Scenario: 报告包含审批区
- **WHEN** 报告生成完成
- **THEN** 报告末尾必须包含完整审批确认区，格式整齐，适合打印
