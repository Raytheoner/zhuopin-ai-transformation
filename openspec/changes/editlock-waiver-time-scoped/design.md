## 二、写死项落地（D1–D4）

### D1 取材面＝时间维（本持锁窗口的 acquire note）

- ⑹ 改为**只**从 `existing.get("note")` 取豁免；不再接受队列行文本。
- **实现上必须与另两项解耦**：现有 `waiver_sources` 继续原样喂给 `_auto_sync_followup_reply_state`（`转态豁免：`）与 `_opener_guard_violations`（`opener豁免：`）；`_registration_completeness_violations` 改为单独接收 note。
  > 🔴 这一条是本包最容易做错的地方：图省事直接把 `waiver_sources` 收窄成 `[note]`，会**顺手改掉另外两道门禁的对外语义**，而它们既没有立项、也没有取证、更没有单测覆盖这次变化。**只收窄本项。**
- 拒绝文案里的「或本次触碰的队列行内写…」一句同步删掉——**留着一条已经不生效的出路，比没有出路更坏**。

### D2 结构化条目

格式（与 `.claude/rules/队列与落库.md` 2026-09-07 止血口径逐字一致）：

```
登记豁免：<仓库根相对路径>[；<路径>…]（作者 <OP 号>，到期 MM-DD）
```

- **分隔符**：路径之间用全角 `；`（止血口径写法）；同时接受半角 `;` 与顿号 `、`——三者都是本仓库既有正文里事实上会出现的写法，为分隔符差异拒绝一次合法豁免属于纯噪音。
- **反引号可选**：`` `路径` `` 与裸路径都接受（止血口径示例里两种都出现过）。
- **有效路径判定**：该路径在仓库工作树内**存在**，**或**出现在本次 `release` 取得的脏文件集合中（后者覆盖「删除」形态的脏文件——它在磁盘上恰恰不存在）。
- **只放行点名件**：`uncovered` 中被点名的移出，**其余照常阻断**，拒绝文案里明确标出「本次豁免点名了 M 个、仍有 N 个未点名」。
- **fail-closed**：出现 `登记豁免：` 但解析不出任何有效路径 ⇒ 走 D3（拒绝），**不退化成旧的「全放行」**。
- `作者` 与 `到期` 缺失时的处置见「决策点 3」。

### D3 泛豁免拒绝

- 拒绝文案给且只给**两条**出路：
  1. 为这些文件登记 §二 批次（`append-row --section 二`，文件清单写仓库根相对完整路径）；
  2. 在 `acquire --note` 里**逐个点名**（附格式示例）。
- **刻意不给第三条**：不提「找总线」「等 sweep」之类——第三条出路的实际作用是让前两条都不必走。
- 泛豁免与「压根没写豁免」的拒绝文案 **必须可区分**：前者要明说「检测到 `登记豁免：` 但未点名任何有效路径 ⇒ 按无豁免处理」，否则写豁免的人会以为工具没读到他那句话，进而写得更宽。

### D4 孤儿升格

- 新增阈值常量（**独立于** `ORPHAN_ALERT_THRESHOLD_HOURS = 3`）：`ORPHAN_SECTION_FOUR_HOURS = 6`。
- **只加一个独立函数 ＋ 一处调用**（派单件 §一 的并行约束：`#479` sweep-manifest 同碰本文件）：
  - 函数 `_escalate_long_lived_orphans_to_section_four(repo_root, log, dry_run)`，**自己读** `reports/sweep-orphan-state.json`（`first_seen` 已在里面），**不改** `_track_and_alert_orphan_paths` 的签名与返回值；
  - 调用点一处，放在两份队列文件的循环**之后**（循环内调用会让同一轮登两次）。
- **当日去重**：在既有 orphan-state 条目上加字段 `section_four_logged_on: "YYYY-MM-DD"`（本机本地日期，`Get-Date` 同源）。同一路径同一天只登一次；跨天且仍是孤儿则再登一行（它确实是新的一天里仍然没人管）。
- **写队列的方式**：走既有 CLI ——`acquire --who sweep-commit --reserve 1 --section 四` → `append-row --section 四` → `release`。sweep 身份对 ⑹ 有既有身份豁免，不会被自己造成的脏工作区挡住。
- **§四 行内容**：文件清单（≤10 条，超出写「…等 N 个」）＋ 每个文件的首见时间与存续小时数 ＋ 两个选项 `(a) 代登 §二 批次入库` / `(b) 丢弃（作者线自行处置，本行销号）`；**等谁 ＝ Shao Peishen**。
- 🔴 **默认项＝无**（派单件写死）。理由与 CLAUDE.md §5「默认项只在两个前提下成立」一致：不答的代价是「孤儿继续躺着」（停在原地）没错，但**执行者是谁取决于答案本身**——(a) 由值周代登、(b) 由作者线处置，机器猜不出，猜错就是替人决定了别人文件的去留。
- **不做的三件事**：不自动 `git add`／`commit` 任何孤儿；不替人判断内容该不该入库；不因升格失败改变 sweep 本轮退出码（同既有告警惯例，失败只留一行日志）。

## 三、决策点（🟡 待 Shao Peishen 一字母；(x) ＝ 默认项）

### 决策 1 —— design 是否批准、apply 范围

- **(a) 批准，按 D1–D4 一次 apply**（推荐 ✅，默认项）。代价：一次改两个工具（编辑锁 ＋ sweep），apply 期需同时核 `#455`（编辑锁写侧）与 `#479`（sweep-manifest）两条分支的 ff 状态。收益：止血与升格通路同时落地——**只做 D1–D3 会让「不许泛豁免」在没有替代出路时先生效**，那正是把会话逼回「随手写更长的泛豁免」的形状。
- **(b) 只 apply D1–D3（编辑锁侧），D4 另立一包**。代价：孤儿仍只有企微推送这一条通路，还是靠人偶然看见；且 (a) 说的「先收紧再给出路」风险成真。收益：本包触碰面缩到一个文件，与 `#479` 完全无冲突。
- **(c) 退回重议**（写明退回哪一条）。

### 决策 2 —— 持锁窗口内才发现需要豁免时，走哪条出路（**D1 的直接后果，真开放点**）

D1 把取材面锁死在 acquire note 上，而 note 在窗口内改不了（`release` 无 `--note`）。于是一个已经持锁的会话，若在窗口中途才发现工作区有必须豁免的脏文件（典型：**另一个并发会话**在这期间弄脏了文件），note 里不可能事先写上它。

- **(a) 就这样，只留「代登 §二 批次」一条路**。代价：并发场景下会话可能**卡在无法 release 的状态**——它得替别人的文件登一条批次才能脱身，而 2026-09-07 的止血口径明确规定「载荷 `队列回写待补/*.json` 与在跑会话的件不代登」⇒ 存在真的无路可走的组合，最坏结果是锁挂到 30 分钟自动陈旧（正是 `#416` ⑶ 一开始要治的那个形态）。收益：口径最纯，取材面只有一个。
- **(b) 给 `release` 加 `--waiver "<结构化豁免>"` 命令行参数**（推荐 ✅，默认项）。它**比 note 更符合 D1 的原则**——随进程存在、随进程消失、一个字都不落盘，不可能被下一次持锁捡到；理由同 `进度豁免：` 的既有惯例写进锁 `history` 留痕，`release` 输出照常打印。格式与 D2 完全相同（结构化、点名、fail-closed），泛豁免同样按 D3 拒绝。代价：多一个 CLI 参数，且写脚本的人可能把它硬编码进封装——但硬编码一句泛豁免在 D3 下会被拒，硬编码点名豁免则等于把点名固化，值周巡检 grep 得到。
- **(c) 保留「本次触碰的队列行」作为补充取材面，但要求结构化＋点名**。代价：`#382` 那类落盘残留只要点了名就仍然会被后来的持锁窗口捡到——**这正是本包要治的那件事，只是变窄了**；D1 写死的「落盘文本一律不算」被打回一半。收益：零新增参数。

### 决策 3 —— `到期 MM-DD` 缺失时的缺省（派单件 Open Question ①）

前置事实：D1 之后豁免**随锁而灭**（锁最长 30 分钟自动陈旧），`到期` 因此主要是**留痕与可读性**字段，而不是有效期的主要防线；但它必须可判——写了一个已过去的日期就该失效（派单件要求的单测之一）。

- **(a) 缺失 ⇒ 缺省为「当日有效」**（推荐 ✅，默认项）。判据：年份取本机当前年，若 `MM-DD` 比今天早 180 天以上则按次年解（跨年时 `12-31` 与 `01-02` 不会互相误判）；`到期` 当日 23:59:59 前有效。代价：与派单件的「建议 1 天」差半天。收益：**豁免活不过它被写下的那一天**，与「随锁而灭」同向，读者不必去想「1 天是从几点算起」。
- **(b) 缺失 ⇒ 缺省 1 天（次日 23:59:59 前有效）**，照派单件建议。代价：跨零点持锁时一句豁免可以横跨两个日历日，判据要多解释一次；收益：与派单件字面一致。
- **(c) `到期` 必填，缺失即解析失败 ⇒ 按 D3 拒绝**。代价：止血口径生效以来已有人按格式写、也有人只写路径，(c) 会把后者一并拒掉，头几天噪音明显；收益：口径最硬，没有缺省可争。
