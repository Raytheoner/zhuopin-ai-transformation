# Change Proposal: SC2 收货报表 BizType316 子集

> 状态：正式 OpenSpec 供审稿，技术 design 尚待批准；不是实施、真实查询或生产授权。
>
> 场景：既有 SC2 深化；承接 #667。独立于 #654 三项替换与 #538 历史差异。#277 业务口径已答，勿重问。

## Why

现有 SC2 收货链路已提供四个对应指标和一般收货明细，但 connector 返回对象、SC2 收货行模型和快照均不携带 BizType。当前指标及 CSV 因此不能证明只纳入 BizType316。Shao Peishen 已在 §四 #277 明确批准新收货报表的四指标与对应明细只计316，同时明确 API 省略参数时仍不筛选、旧冻结/缓存不重算、缺类型或过滤未核实时报告缺口。

本变更让这条已答口径在技术链路可证明、可追溯地生效，保留旧期冻结和未在 #277 范围内的其它收货指标。

## What Changes

- 为收货源建立显式 `bizType=316` 请求或经验证的逐行类型过滤能力；API 未传类型仍按不筛选处理。
- 从共享 `receipts` 中隔离出一个来源完整、过滤状态可审计的 316 子集，供以下四指标与同源明细使用：
  - 收货行数：沿用现有按收货行计数的实现；
  - 收货数量：沿用现有收货数量汇总；
  - 收货金额：沿用现有数量 × 单价汇总；
  - 到货供应商数：沿用现有非空 `supplier_name` 去重。
- 若类型/过滤/行集完整性未知，不把未知当零、不按单号前缀推类型、不导出一个看似完整的316明细。
- 给新期的类型和过滤能力证据使用显式 schema/缓存身份；保留旧冻结、旧缓存，不回算、不覆盖。
- 复用现有指标展示与收货明细交付能力；仅对316四指标及其对应明细补齐明确的范围标识/缺口说明，不重做 UI。

## Capabilities

### New Capabilities

- `sc2-receipts-biztype316`：为新收货报表定义可证明的316来源范围、四指标/明细同源、缺字段粒度及历史冻结保护。

### Modified Capabilities

无。已查现行 `sc2-feed-source` 与 `sc2-metric-engine`，本包在既有窗口、纯函数、来源失败上抛及原公式之上新增316 scope，不改其旧语义，不修订历史SRM文字。本包只新增该独立能力规格。

## Out of Scope

- 旧期周报或数据集快照重算、补BizType、重新解释历史58→90差异、关闭或重开 #538。
- #654 三项指标替换；不与本 change 合并。
- 任何新的退货/作废排除规则、金额定义变更、供应商身份主数据改造或组织默认值硬编码。
- 真实 ERP 查询、服务端代码修改、刷新/重算、部署、发布、自动推送开关或对外发送。
- 泛化为所有域的通用过滤/快照/明细框架。

## 验收与晋档条件（强制，四档口径）

本次增量的**交付证据层为档1（mock）**，仅以合成 `MOCK-*` 数据证明筛选/失败关闭接口、四指标与明细同源、字段缺失隔离及共享旧收货行为不变；它不是把既有 SC2 场景降档，历史/现行场景档位保持原记录。档位定义为：档1 mock、档2真实、档3内部服务、档4对客。

- **档2（真实）晋档条件**：本包design与具体实施计划获批；真实来源的逐行BizType语义及分页完整性经证，或B路线服务端316过滤能力经独立验证；专业口径签认及实名知识持有人/Backup到位；获授权的真实查询通过审计，并对四指标及同源明细完成可复核的数据核对。未满足前只停留在档1证据层。
- 价值指标推荐质量型：四指标与明细同源对账差异及缺口可见性；具体度量定义、验收阈值与 Champion 基线目前 **unknown / 待确认**，不得虚构指标、数值或阈值。档3/档4的本增量晋档条件也 **unknown / 待确认**。
- 该变更的运行时规则是确定性BizType/字段筛选，不含 LLM 判断；因此针对运行时判断的黄金集 **不适用**。档1仍需确定性合成用例，但不把它称为LLM黄金集。
- Owner/Backup 未实名确认前不得进入专业签认或真实业务阶段；这不构成 Native mock 的否决。任何技术实现仍须先批准design与具体实施计划。

## Impact

- 仅影响新316 scope：connector来源适配、SC2 typed subset、四项既有收货指标及其对应明细、scope/version快照和缓存身份。
- `dataset.receipts` 全量共享集、旧 `ReceiptRecord` 类型/默认值、其它共享指标、旧冻结报告均保持既有行为；不重算、不覆盖。旧 #654 三指标变更与 #538 问题不纳入本增量。
