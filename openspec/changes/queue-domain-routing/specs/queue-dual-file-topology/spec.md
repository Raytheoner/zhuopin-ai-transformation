## MODIFIED Requirements

### Requirement: §二 域路由
§二 批次行的域归属 SHALL 由其所在的物理文件决定，不引入独立的 `[D:]` 字段；写入方在登记
§二 批次时 SHOULD 显式选定目标文件（机制环境或业务场景），未显式选定时 SHALL 默认落机制
环境文件，且 MUST 向调用方回显"本次使用了默认值"这一信号（不得完全静默）。

> 📌 **来源**：`queue-dual-file-split` design 决策点 3 原定"未声明目标文件时 MUST 拒绝
> 写入"，apply 阶段发现会让当时大量在途、尚未加 `--domain` 参数的调用方当场失败，故落为
> 本条描述的默认值行为；`queue-domain-routing`（本包）2026-09-05 复核后确认
> 该行为已运行且经交叉校验 Requirement 兜底，收编为目标态，移除此前"归档时如实登记的
> 实现差异"临时标注。若未来改为真拒绝，需先完成调用点普查与迁移（见本包 design.md
> 决策点 1 备选项），届时本 Requirement 需另行修订。

#### Scenario: 未声明目标文件时默认落机制环境文件
- **WHEN** 调用 §二 批次登记（`append-row --section 二`）且未显式指定目标物理文件
- **THEN** 写入落到机制环境文件，命令输出中包含一行提示说明"使用了默认值，建议显式指定
  目标文件"，不静默隐藏这一事实

#### Scenario: 显式声明目标文件时按声明路由
- **WHEN** 调用 §二 批次登记并显式指定目标物理文件（机制环境或业务场景）
- **THEN** 写入落到调用方指定的那一份文件，不受默认值逻辑影响
