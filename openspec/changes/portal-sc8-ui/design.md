# 设计：SC8 门户只读展示

## 范围与依据

沿用 `docs/superpowers/plans/2026-10-08-portal-ui-rollout.md` 阶段4和 `portal-q2-ui` 公共视觉基线。目标文件只限 SC8 `webapp.py` 的展示层和新增展示契约测试；隔离树须在实施前重新核对授权、HEAD 与工作区状态。现有 `/materials`、`/cases`、`/cases/review` 等路由及服务边界不重构。

## 展示模型

- 页面按“结果/来源/状态/责任”组织：保留源字段与源时间；状态颜色始终带文字标签。
- DOS、状态颜色、规则版本仅显示源结果，不在模板中推导阈值或重新计算。
- 区分物料看板、成品订单和案例记录；不跨维度合并或做新的汇总。
- 数据陈旧、未签认、服务错误、权限不足、缺资料分别呈现；不以 HTTP 成功或页面可打开代表业务可用。
- 现有案例推进、草稿、批改和审计入口保持原控制器及权限；门户展示本身只读。
- 刷新快照与重算仍调用其原有显式动作；mock契约测试只调用渲染函数/测试客户端的纯展示路径。

## 失败与安全处理

缺字段显示“未提供/未接入”；超时显示最近已知时间（若源提供）并标注非当前；动态文本按既有转义方式处理。没有新自动生成工件或依赖。

## 验证

新增 `4-数字员工/采购部/SC8-客户订单交期智能承诺/tests/test_webapp_ui_contract.py`：构造 mock 数据，覆盖完整/缺字段、陈旧/错误/待签认状态、物料独立性、长中文与HTML转义、无副作用；运行该子项目的指定测试文件，不跑全量矩阵、不生成或读取真实六键数据。独立 review 后形成证据；部署及真实 LAN 核验另行授权。
