## ADDED Requirements

### Requirement: 毛理论用量与标准损耗基线计算

系统 SHALL 按毛理论口径（Paul 2026-06-28 选）逐子件计算：理论净用量 = Σ_成品(产出数量 × BOM `qty_per_unit`)，**不含损耗**；标准损耗基线 = 理论净用量 × `loss_rate`（`m_scrap`）。计算 MUST 为纯函数（无副作用、可单测），同一子件被多个成品共用时按成品累加。

#### Scenario: 单成品单子件理论净用量
- **WHEN** 成品 P 产出 100、BOM 中子件 C 的 `qty_per_unit=2`、`loss_rate=0.05`
- **THEN** 理论净用量 = 200；标准损耗基线 = 200 × 0.05 = 10

#### Scenario: 多成品共用子件累加
- **WHEN** 子件 C 同时用于成品 P1（产出 100，用量 2）与 P2（产出 50，用量 3）
- **THEN** 理论净用量 = 100×2 + 50×3 = 350，按各自成品的 `qty_per_unit` 累加

#### Scenario: 产出为零或 BOM 残缺
- **WHEN** 某成品产出为 0，或其 BOM 在 `failed_ids` 中
- **THEN** 不产出该成品对子件的理论用量贡献；BOM 残缺者整料号标"待人工核"，不计入可自动结案集合

### Requirement: 总差异与差异率计算

系统 SHALL 逐子件计算总差异 = 实际投料 − 理论净用量，差异率 = 总差异 / 理论净用量（理论净用量为 0 时差异率标"NA·无理论基准"），并保留差异符号（正=超用，负=少用/疑短缺）。

#### Scenario: 正向超用
- **WHEN** 实际投料 215、理论净用量 200
- **THEN** 总差异 = +15，差异率 = +7.5%

#### Scenario: 负向少用/疑短缺
- **WHEN** 实际投料 190、理论净用量 200
- **THEN** 总差异 = −10，差异率 = −5%

#### Scenario: 无理论基准
- **WHEN** 理论净用量 = 0 但有实际投料
- **THEN** 差异率标"NA·无理论基准"，总差异保留绝对值，料号标"待人工核"

### Requirement: 黄金基准回归（确定性零偏差）

系统 SHALL 对 `data/golden/` 合成样本重跑全部计算，逐项与预期比对，确定性计算（理论净用量/标准损耗/总差异/差异率）MUST 零偏差通过。

#### Scenario: 合成 golden 零偏差
- **WHEN** 对合成对账样本重跑对账引擎
- **THEN** 每个子件的理论净用量/标准损耗/总差异/差异率与预期逐项相等，任一不等即回归失败
