# 设计：SC2 门户只读展示

## 范围与依据

沿用 `docs/superpowers/plans/2026-10-08-portal-ui-rollout.md` 阶段4公共门户视觉基线。只调整 SC2 页面渲染及新增展示契约测试，不改变 `/procurement/sc2/` 路由、数据源、周次窗口、计算或写审计流程。#538继续由原责任人/流程处理。

## 展示模型

- 顶部展示统计期、来源和源更新时间；缺字段显示未提供。
- 数量和指标值保留源值，并标注“口径待核”；不推断单位、统计对象或周期含义。
- 空周次、字段缺失、真实0、陈旧数据、超时和服务不可用分别呈现。
- 长供应商名允许换行或在行容器内滚动；动态文本安全转义。
- 不新增重算/确认/提交控件；保留现有入口和身份、权限、审计行为。

## 超时核验

实施前先检查已有超时证据和不触发数据读取的测试入口。服务是否可用只能由当次授权核验得出；mock契约测试不能证明服务在线。

## 验证

新增 `4-数字员工/采购部/SC2-采购周报自动生成/tests/test_webapp_ui_contract.py`，使用构造数据覆盖源元数据、待核数量、空周次/零值/资料不足、超时状态、长供应商名和HTML转义；只运行该子项目定向测试，不拉真实数据、不重算、不写审计。独立 review 后整理发布准备，实际发布需另行授权。
