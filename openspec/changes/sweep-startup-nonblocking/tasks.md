- [x] 2.1 `_push_any_unpushed_commits`：fetch 返回 `False` 时记录后 `return`，**跳过 ahead 计算与推送**（不依据可能陈旧的 `origin/master` 引用做判断），继续本轮。

- [x] 2.3 更新该函数 docstring，补记本次两处降级及其理由（沿 #194→#309-F→#328 的记法惯例）。

## 3. 收尾段降级（决策点 2＝(a)）
