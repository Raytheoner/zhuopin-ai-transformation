# global-memory-inspection-and-root-ratchet Design

> 待 Shao Peishen design 审。下列 D1-D6 是需要他点头的决策点，其余为实现细节。

## D1 🔴 只在 CC 侧生效——为什么这**不是**「只覆盖一半的门禁」

`#381 ⒞` 定过一条硬判据：**只覆盖一半的门禁比没有门禁更危险**（它制造「已被机器守住」的错觉）。本包必须先答清楚自己是不是那种情形。

**答：不是，因为两者的形状不同。**

- `#381 ⒞` 针对的是「**同一个动作两个桌都能做，但只有一个桌有门**」——Cowork 和 CC 都能裸手改队列，只有 CC 侧有探测器，于是没读过纪律的 Cowork 会话畅通无阻。
- 本包针对的是「**只有一个桌能做**」——`~/.claude/CLAUDE.md` 在仓库外，Cowork 沙箱**连读都读不到**（`OP-0829-W` 实证：`Read` 明确拒绝「outside this session's connected folders」，只能走 Windows-MCP 本机通道）。**改不了的地方不需要门。**

⇒ **判别一问留作通用判据**：*没有这道门的那一侧，能不能做出这道门要拦的那个动作？* 答「不能」，则单侧覆盖是半径匹配，不是半覆盖。

## D2 A1 的路径抽取是形状启发式，不是真值——两向失手都先说清

复用 `_looks_like_declared_path` 那条教训（形状判据不是真值），本包同样两向如实登记：

- **漏认**（真路径没被抽出）⇒ 该片段不参与核验，退化为现状，**不制造新破坏**；
- **误认**（散文被当成路径，`Test-Path` 假）⇒ 报一条假阳性，人核一眼即可。

🔴 **取舍方向与覆盖校验相反，须显式**：`_looks_like_declared_path` 宁可漏认（漏认只是退化，误认会把整批跳过＝把 sweep 关掉）；**本包宁可误报**——因为**漏报是零信号**，正是本包要消灭的东西，而误报只是多看一眼。

**实现约束**：抽取只认反引号包裹或行内明确的 `C:\` / `~/`  开头片段；`~/` 展开为 `$env:USERPROFILE`；含空格的片段按整段取（本机用户目录含空格，见全局文件自身那条约定）。

## D3 阈值取 48 KB，不取「实测值 + ε」

48,000 B 相对现值 47,863 B 只留 **137 B** 余量：一次寻常小改（加一行指针）就会顶到，当轮告警。**这正是棘轮语义**——不是给瘦身留余量，是让每一次增长都被看见一次。真要加内容，须同批把别处压掉（one-in-one-out），或显式把 cap 调高并说明理由（留痕在 git）。

## D4 受检对象自己不存在时——告警，不崩

换机、路径变、文件被删，`~/.claude/CLAUDE.md` 可能读不到。**「受检对象不见了」本身就是一种失真**，MUST 告警而非静默跳过、更不得让 sweep 整轮中止（同 `#328`「起跑段阻断整轮」那族的反面教训）。

## D5 为什么机器只报、不自动修

改本机 Claude 配置层每次都须他授权（本役定夺 1 即为一例：修订稿先出、他答 (a) 之后才动手）。**机器有权发现，没有权处置**——这条边界与「对外发送与 L2 人工门禁永不代办」同族。

## D6 值周巡检读什么

sweep 日志新增两节（全局记忆巡检、棘轮提示）。值周清单同步加一行：**「全局记忆巡检有红即当周处理，不跨周」**——理由是它报的都是零信号失真，拖一周＝多一周无人知情。

## D7 子项 E：为什么**不**改 `_count_mechanism_wip` 的计入口径（2026-08-30 并入）

最直觉的修法是「`partial` 不计入可动」——一改 WIP 就从 27 掉到 10。**否掉，理由一句：`partial` 里确有真可动者。** 2026-08-30 分诊实测，17 个 partial 里 `#96`（Cowork 半完成、**CC 半待领**）、`#328`（并入新子项待做）、`#366`（缺口仍在）、`#434`（Cowork 可做）都是现在就有人能动手的。改口径会把它们一起变没，**用一个静默的漏报换掉一个吵闹的超限**——正是 D2 那条取舍要防的事。

⇒ **改的是「谁做分诊」，不是「怎么计数」**。机器扫出候选、人一眼过目改判（2026-08-30 那次 8 行改判耗时约 10 分钟，瓶颈从来不是判断难，是没人想起来做）。

🔴 **本子项与 D2 同族，取舍方向一致：宁可多列几条候选，不可漏掉该改判的行。** 误列一条，人核一眼跳过；漏列一条，它就继续永久占配额且无人知情。

**另一条必须写死的边界**：候选清单**只建议、不自动改**（同 D5）。状态字段是行的所有者对自己工作的判断，机器越权翻转会制造比超限更难查的问题。
