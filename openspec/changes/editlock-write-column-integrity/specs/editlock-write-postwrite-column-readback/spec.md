## ADDED Requirements

### Requirement: 写入后须从磁盘回读并复核列数，不符即自动回滚
`edit-row` 完成一次写盘操作后，SHALL 立即从磁盘重新读取目标文件、定位刚写入的那一行、用 `queue_table.split_row_cells` 重新切列，确认列数等于该分区的预期列数（`SECTION_COLUMN_COUNTS`）。

本项校验 MUST 在**真实落盘之后**对**重新从磁盘读取**的内容执行，MUST NOT 仅对写盘前拼装在内存中的字符串做等价判断——只验证内存拼装结果，不能证实真正落到磁盘上的字节是否符合预期。

若回读列数不符，工具 MUST 将目标文件内容还原为写入前的完整字节（写入前内容 MUST 在写盘动作发生前被完整保存，作为回滚源），并明确提示"已回滚，文件已还原至写入前状态，本次改动未生效"；本次 `edit-row` 调用 MUST 以非零退出码结束。

#### Scenario: 写入后回读列数不符，自动回滚
- **WHEN** `edit-row` 写盘后重新读取该文件、对刚写入的那一行用 `split_row_cells` 切列，得到的列数不等于该分区预期列数
- **THEN** 工具将文件内容还原为写入前的完整字节，提示"已回滚"，本次调用以非零退出码结束

#### Scenario: 回滚结果须逐字节等于写入前状态
- **WHEN** 触发了上一 Scenario 描述的自动回滚
- **THEN** 回滚后的文件字节 MUST 与写入前完全一致（逐字节比较），而不仅仅是"回滚后重新计算列数又恰好正确"这一弱断言

#### Scenario: 正常写入不触发回滚（非恒真自证）
- **WHEN** `edit-row` 写盘后重新读取、对刚写入的那一行重新切列，得到的列数等于该分区预期列数
- **THEN** 不触发回滚，本次调用正常结束，文件保留新写入的内容——证明回滚只在列数真的不符时发生，而非每次写入都被撤销
