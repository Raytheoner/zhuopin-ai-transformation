## 3. 实现——校验 B（写入后列数回读）

- [ ] 3.1 `cmd_edit_row` 写盘前保存"写入前完整文件字节"作为回滚源
- [ ] 3.2 写盘后立即 `read_text` 重新打开文件，定位刚写入的那一行，用 `queue_table.split_row_cells` 重新切列
- [ ] 3.3 列数不等于该分区预期列数（`SECTION_COLUMN_COUNTS`）时，用回滚源覆盖写回文件，报错并明确提示"已回滚，文件已还原至写入前状态，本次改动未生效"
- [ ] 3.4 回滚路径需保证**原子性描述准确**——如实现依赖两次独立 `write_text` 调用（先写新内容、失败后再写回滚源），需在提示或注释中如实说明这不是文件系统级原子操作，若中途进程被杀，文件可能停在"已写入新内容但未回滚"的状态，此为已知残余风险，写进 proposal 或本文件（不得在实现阶段才发现却不登记）

## 4. 实现——`--repair` 逃生入口
