# Design: editlock-causal-assertion-falsifiability-gate

> **本设计不重开审议**——三选一（收窄+挂校验④ ／ 判定无法机制化删除 ／ 维持现状）已由 Shao Peishen 于 2026-08-07 拍板选 (a)，完整讨论见队列 #285 与 `1-转型规划/0-全景路线图/环境保障线-三行机制方案定稿-285规则退休-267签字材料-203前提复检-2026-08-07.md` §一。本文档只记录**如何落地**这一决定，供后续 session 追溯实现细节。

## 决策点 1：证伪命令检测的判据形态

**已定案**：状态列（剔除引号包裹片段后）同时满足「含 P0/P1 定级 token」时，MUST 在同一单元格内找到至少一处反引号 `` `...` `` 包裹的非空片段。检测**只判存在性，不判该片段是否真的是一条能证伪该断言的命令**——这是拍板文原话明确的边界（"只判有没有、判不了对不对，覆盖 2/3"）。

**实现**：复用 `工具-共享文档编辑锁.py` 已有的 `BACKTICK_SPAN_RE = re.compile(r"`[^`]*`")`（`_cell_has_bare_pipe`/`append-row` 已在用），对 `_strip_quoted_spans(cells[5])` 之后的文本做存在性检测；若该文本同时命中 `P0_P1_TOKEN_RE` 且 `BACKTICK_SPAN_RE.search(...)` 为 `None`，追加一条 violation。

**为何不新造正则**：`P0_P1_TOKEN_RE`／`QUOTED_SPAN_RE`／`_strip_quoted_spans`／`BACKTICK_SPAN_RE` 均已存在于同一文件，本变更是四者的一次新组合，不引入新的解析能力（与 #241 `extract_target_filename`／#258 append-row 的反引号解析是同一套基础设施）。

## 决策点 2：与既有④校验（未核实字样）的关系

**已定案**：新校验与既有④（P0/P1 + "未核"/"未做的核实"字样共现即拒绝）是**两条独立的 violation 来源**，都挂在同一段代码里（同一个 `if label == "一":` 分支内，状态列已剔除引号的文本上分别跑两次检测）。一行如果同时缺证伪命令又带"未核"字样，会在 violations 列表里出现两条提示（不互斥、不去重），这是刻意的——两类问题成因不同，分开提示不合并成一条模糊消息。

## 决策点 3："防线4"正文的实际位置与降级方式

**实测发现（本变更 apply 阶段核实，属实现细节而非重新审议）**：队列 #285 行文与拍板文本身引用的"opener §六防线4"，**字面路径并非**稳定的 `专线opener模板库.md`（该文件当前 §六 是"变量速查"，与"防线"无关，grep 全文 0 命中）——"防线"清单实际生活在环境保障线自己的滚动接力文件里，历史上最后一份含完整正文的版本是 `1-转型规划/0-全景路线图/开场prompt-【Cowork】环境保障线-接力交接-2026-08-04.md` §六「反面清单」第 4 条；该系列已改名为"环境总线"并滚动到 `开场prompt-【Cowork】环境总线-接力交接-2026-08-08.md`，其 §六已整体改写为"纪律段（引用条目名）"精简格式，**这一条已经不在其中、且没有留任何指针**——即"降为一行指针"这个动作在最新滚动版里被"直接消失"抢先替代了，不是本变更导致，也不是本变更能追认的既成事实（消失≠指针，指针要求可 grep 可追溯）。

**落地选择**：既然"opener 模板库"字面指向 `专线opander模板库.md`，且该文件是全项目唯一**不随 session 滚动替换**的稳定权威模板（其余候选都是会被下一次接力覆盖的临时快照，在其中留指针无法长期存活），**指针落在 `专线opener模板库.md`**——新增一条简短说明，供任何未来读到 CLAUDE.md 里"防线4"这一提法的人能 grep 到落点。不追改历史滚动接力文件（`-08-04.md` 等属过往快照，编辑它们不会被任何未来 session 读到，价值低于成本）。

## Non-Goals

- 不处理"想过但用了错的证据"这一形态（#221）——拍板文已明确排除，需要更强的语义判断，超出本变更范围。
- 不新增扫描面（不检查状态列以外的其它列，不检查§一以外的分区）。
