## ADDED Requirements

### Requirement: 落库 sweep SHALL 常驻监测「终态但引用不可核」的跟进信
落库 sweep SHALL 新增一类**常驻状态告警**，复用既有 `_track_and_alert_standing_state` 框架，MUST NOT 新造一套告警机制。

命中集合 ＝ README 中状态为 `📥` 且满足以下任一的信：

1. 状态列含「未经人工逐字确认」字样（机器代写存量）；
2. 或不带合格回灌引用，**且**其状态日期在截止日期之后。

截止日期之前（含完全无日期）的行 MUST NOT 进入命中集合 —— 它们走历史豁免。

本告警的存在理由 ＝ 机器留下的「未经人工逐字确认」这句话此前**没有任何消费方**：它写下了一个需要动作的事实，却没有承接方。

#### Scenario: 机器代写的存量行被报出
- **WHEN** README 中存在 4 行状态含「未经人工逐字确认」
- **THEN** 告警列出这 4 个信编号

#### Scenario: 历史豁免行不进告警
- **WHEN** 某行状态为 `📥 已回件并回灌`（无日期、无引用）
- **THEN** 该行不出现在告警中

### Requirement: 告警 key SHALL NOT 包含任何会变的量
key MUST 为信编号（如 `质量部#10`），MUST NOT 含日期、行号、小时数、字节数或任何随时间变化的值。

把会变的量放进 key，会使每一次变化都被当成一个新问题重新告警，同时把旧 key 判为「已解除」——常驻状态与事件的分界线正在于此。

#### Scenario: 同一封信持续未处置不重复刷屏
- **WHEN** 同一封信连续多轮命中
- **THEN** 按框架既定的告警间隔节流，不因日期推进而被当作新问题

### Requirement: 告警 SHALL 有两条可自动解除的出路
本告警 MUST 在下列任一情形发生后**自动解除并播报解除**，MUST NOT 要求任何人手动关闭：

1. 该行补齐合格回灌引用（并去掉「未经人工逐字确认」字样）；
2. 该行被降回第九态 `📨 回件已到，待拆件`。

🔴 第 2 条 MUST 存在：只有「确认」一条出路的告警会逼人在没核实的情况下点确认，而那正是本变更要修的那件事。

#### Scenario: 补齐引用后解除
- **WHEN** 该行补写了合格引用
- **THEN** 下一轮该 key 消失，输出含「已回落」播报

#### Scenario: 降回第九态同样解除
- **WHEN** 该行状态被改回第九态
- **THEN** 下一轮该 key 消失，输出含「已回落」播报

### Requirement: 本告警 SHALL 每轮回显，零命中亦不省略
无论是否有命中，本检查 MUST 每轮打印当前统计：`📥` 行总数、其中带合格引用数、不带引用数、走历史豁免数。

零命中时若连回显都没有，本守卫与「建成 9 天、每天在跑、却从来没有真正发出过一条消息」那个反面教材在外观上无法区分。

#### Scenario: 零命中仍有回显
- **WHEN** 本轮无任何命中
- **THEN** sweep 日志仍含本检查的四项统计

#### Scenario: 统计取不到不得判为合规
- **WHEN** README 读取或解析失败
- **THEN** 输出明确写「未取到，**不据此判为合规**」，MUST NOT 静默按零命中处理

### Requirement: 本告警 SHALL 自带退休条款
本告警属**存量清算型**：机器代写终态的通道在本变更后已被关闭，命中集合在设计上将趋于恒零。

⇒ 上线后连续 30 天零命中，SHALL 触发一次退休评估（退休，或降为纯回显不再发告警），MUST NOT 无限期保留一个永远绿着、没人再看的检查。评估结论 MUST 落队列行留痕。

#### Scenario: 连续零命中触发退休评估提示
- **WHEN** 本告警连续 30 天零命中
- **THEN** sweep 输出一行退休评估提示，指向承接该评估的队列行

### Requirement: 抑制窗口 SHALL 大于落库周期
判定「超过 N 小时未见回灌证据」的 N MUST 不小于落库周期的两倍，建议初值 6 小时，首月只告警不调参。

正常路径上 `📥` 与其引用在同一次持锁窗口内一并写入，根本不经过「有终态无引用」的中间态；N 取过小只会在 sweep 与拆件班并发时制造误报。

#### Scenario: 同一持锁窗口内完成的转态不触发告警
- **WHEN** 拆件写入 `[R:…]` 与终态引用后立即 release，sweep 随后一轮运行
- **THEN** 该信不出现在告警中
