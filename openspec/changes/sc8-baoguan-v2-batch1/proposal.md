# sc8-baoguan-v2-batch1 Proposal

## Why

采购专员（姚祖怡/汤易水）实盘保供看板后反馈一组真实缺陷与需求（Paul 2026-07-06 转达）。其中"有货却判瓶颈"类（二/三/四误判）根因是**现货净额未上线**——已由 `stock-api-inventory-source` 修复（`SC8_NET_INVENTORY`，待部署+专员黄金重核后翻开）。本变更包收口净额修复覆盖不到的**结构性缺陷与看板增强**（批1，口径清晰/工程可直接做的部分；口径重的 一.3 主料替代料 / 四 部分齐套 走批2 专线）。

## What Changes

- **五 递归展开半成品（真缺陷，F 开头共性）**：现 `load_real_bom(max_depth=1)` 只展开直接子件，遇半成品（S 开头）当叶子、不再下钻。改为**递归展开到叶节点**：F 成品 → S 半成品 → 其 BOM 子件，齐料日/瓶颈按多层滚动。
- **二.4 半成品自身库存净额（真缺口）**：半成品 S 自身有现货（如 S02Y.0035 委外仓 264）时，其净需求 = 毛需求 − S 自身现货；只有净需求 > 0 的部分才下钻展开子件（1264−264=1000 口径）。与"五"联动（逐层净额后再下钻）。
- **一.1 看板范围过滤**：只显示**计划出货 ≤ 2026-10-31（滚动未来 3 个月）**的成品/半成品行，超窗口不进看板。
- **一.2 未答复子件全展开**：看板/行详情列出**全部未答复子件明细**（现仅显示瓶颈 1 个）——`no_feedback_materials` 已在数据里，补展示。
- **二.2 PO 多行答交核实**：核实 `/purchase/answer` 是否对同一料多 PO 行只取首行、漏取其余行答交（R01F.0005 行40=12-25 / 行50=08-25），漏则修（取最早有效答交，与引擎 srm_index "取最早" 一致）。

## Capabilities

### New Capabilities
- `baoguan-multilevel-kitting`: 保供齐套多层 BOM 展开 + 逐层半成品自库存净额（五 + 二.4）、看板窗口过滤（一.1）、未答复子件全展开（一.2）、PO 多行答交核实（二.2）。

### Modified Capabilities
（无——批1 全部为新增能力；现有 `baoguan-web-service` 判级语义不变，仅在其上叠加窗口过滤/展示增强，作新能力表达。）

## 知识资产三问（强制，全景规划 §1.4 第 2 条）

1. **哪些判断是人脑默会经验？** ① 看板范围窗口（未来 3 月 / ≤2026-10-31，Paul 已显性化，滚动口径待确认是否随月滚动）；② 半成品净额口径（自库存扣减，专员 1264−264=1000 已显性化）；③ 递归下钻停止点（到叶节点/到无 BOM）。
2. **由谁显性化？** 采购 AI 专员（姚祖怡/汤易水，业务口径主笔）+ Paul 拍板；登记进《跨场景前置数据与知识库任务总表》§一.2。
3. **用什么方法提取？** L2 改判判例累积（专员核实误判/漏判逐案校准）+ AI 起草·专家批改（窗口/净额/递归口径）。

## 验收与晋档条件（强制，四档口径）

- **交付后档位**：**档 2（真实数据跑通）**——多层展开+净额在正式库真实数据跑通、专员抽验瓶颈正确。
- **晋档 3 条件**：① 与 `stock-api-inventory-source` 一并经采购专员**保供黄金重核 + 签字**（多层+净额会显著改变四色/瓶颈）；② 全回归不漂移（SC8 现有黄金 flag OFF 零漂移）；③ 专员用真实单确认递归瓶颈、半成品净额、窗口过滤均正确。
- **价值指标**：风险型——保供瓶颈误判率↓（有货子件/半成品不再误判、真瓶颈如 R01H.0021 正确浮现）；工时型——专员保供核对耗时↓。基线由采购专员确认。
- **LLM 判据黄金集**：无 LLM 运行时判断（确定性 BOM 展开+净额+日期），不适用。

## Impact

- **specs**：新增 `baoguan-multilevel-kitting`；改 `baoguan-web-service`。
- **代码**：`sc8/sources.py`（load_real_bom 递归 max_depth）、`sc8/baoguan.py`（多层齐料+逐层净额+未答复全展开+窗口过滤）、`sc8/baoguan_service.py`（窗口过滤入参、递归 BOM 拉取）、可能 `sc8/forecast.py`（estimate_material_arrivals 多层）。
- **红线**：真实取数只读（正式库 read-only API，Paul 2026-07-06 授权）；audit 留痕；对客闸全程 False；多层展开行为变更挂现有 `SC8_NET_INVENTORY` 或新窗口开关，默认不破坏现黄金。批2（一.3 主料替代料 / 四 部分齐套）口径重、单列专线，不在本包。
