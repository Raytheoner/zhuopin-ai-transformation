## Purpose

定义 `工具-共享文档编辑锁.py` release 队列文件时，对"队列行暂缓类结论"与"跟进信 README 发送状态"两者做交叉一致性校验的行为契约，防止"决定写在队列行、但可执行的发送标记未同步移出终态"这类决定与载体分离的失效（2026-08-06 01:30 UTC 真实误发事故，队列 #150/#294）。

## Requirements

### Requirement: 检测队列行的暂缓结论与已点名的跟进信文件
release 锁定目标为默认队列文件时，对本次持锁期间新增/修改的 §一/§四 行，工具 SHALL 检测该行是否同时满足：① 该行的叙述文本（§一 状态列 cells[5]；§四 事项列 cells[1]）含有"暂不发"、"暂缓"、"压着"、"不发"中任一字样；② 该行可提取出至少一个反引号包裹、以 `.md` 结尾的文件名引用（§一 检测输入指针列 cells[3] 与触碰区列 cells[6]；§四 检测事项列 cells[1]）。

#### Scenario: 同时命中暂缓字样与文件名引用
- **WHEN** 一个 §一 行的状态列含"暂不发"字样，且其输入指针列含反引号包裹的 `某跟进信.md` 引用
- **THEN** 工具判定该行"点名了一封跟进信且结论为暂缓"，进入下一步与 README 的交叉核对

#### Scenario: 仅含暂缓字样但无文件名引用时不触发本校验
- **WHEN** 一个 §一 行的状态列含"暂缓"字样，但该行任何列都不含反引号包裹的 `.md` 文件名引用
- **THEN** 工具不对该行触发本校验（既不拒绝也不告警），维持既有①-⑤校验结果不变

### Requirement: 队列暂缓结论与 README 终态"待发"标记冲突时拒绝 release
当一个被检测为"点名了跟进信且结论为暂缓"的队列行（见上一 Requirement），其引用的文件名（取 basename）与跟进信 README「现有跟进信清单」表中某一行「主要事项」列提取出的目标文件标注（同一 `目标文件` 反引号 `.md` 文件名格式）完全一致，且该 README 行「发送状态」列当前值为终态标记 `🆕 待发` 时，工具 MUST 拒绝 release，锁保持占用，提示该跟进信在 README 中仍处于可被每日批处理任务发送的状态。

#### Scenario: 队列称暂缓而 README 仍为待发终态，拒绝 release
- **WHEN** 一个队列行满足"点名了跟进信且结论为暂缓"，其点名的文件名与某 README 行的目标文件标注一致，且该 README 行「发送状态」列为 `🆕 待发`
- **THEN** release 被拒绝，提示信息包含该跟进信文件名与 README 当前状态

#### Scenario: README 已同步为非待发状态时正常 release
- **WHEN** 队列行满足"点名了跟进信且结论为暂缓"，但其点名的 README 行「发送状态」列当前值不是 `🆕 待发`（如 `⏳ 待你审`，或 #294 引入的其它非待发中间态）
- **THEN** release 正常放行,不因本校验拒绝

#### Scenario: 未找到匹配的 README 行时不拒绝
- **WHEN** 队列行点名的文件名在 README「现有跟进信清单」表的任何行「主要事项」列目标文件标注中均无法找到 basename 完全一致的匹配
- **THEN** 工具不因本校验拒绝 release（无法核对不代表冲突，遵循"判不出就不拦"原则）

### Requirement: 反向不一致仅告警不阻断
当匹配到的 README 行「发送状态」列已是终态"已推送"类值（非 `⏳ 待你审` 亦非 `🆕 待发`），而对应队列行本次新增/修改的文本仍含"暂不发"、"暂缓"、"压着"、"不发"任一字样时，工具 SHALL 打印告警提示两者可能不一致，SHALL NOT 因此拒绝 release。

#### Scenario: README 已终态推送而队列行仍称暂缓，告警放行
- **WHEN** 队列行点名的 README 行「发送状态」列已是"✅ 已推送…"类终态值，且该队列行本次新增/修改的文本仍含"暂不发"等字样
- **THEN** 工具打印告警说明两者状态可能不一致，但 release 正常放行,不拒绝

#### Scenario: 事后如实记录已发生的误发不被拦截
- **WHEN** 一个队列行的文本是在事故发生后新增,用于如实记录"本应暂缓但已被机制误发"这一经过,其中包含"暂不发"字样且点名了已处于终态"已推送"的 README 行
- **THEN** release 不因本校验被拒绝,仅告警,允许如实记录类文本正常提交
