# qd-b-semantic-judge Specification

## Purpose

对工作汇总.xlsx「立项门禁」页中 J 列标"半自动"的 10 条 B 类规则（规则 20/21/23/24/26/27/28/77/78/79）用 LLM 做语义判定，输出命中/未命中、证据片段与置信度。置信度口径与 SC8 对齐（高/低二级），低置信一律转人工，不擅自下终局结论；严重度遵从「立项门禁」J 列既定配置，不因走 LLM 路径而擅自升降级。

## Requirements

### Requirement: 半自动语义规则的 LLM 判定

系统 SHALL 对工作汇总.xlsx「立项门禁」页中 J 列标"半自动"的 10 条 B 类规则（规则 20/21/23/24/26/27/28/77/78/79），用 LLM 做语义判定，每条输出 `{规则ID, 命中/未命中, 证据片段, 置信度}`。判定准则（提示词 + 业务判据）为 design 收口项-2，业务方（陈忱/质量）确认后接入；准则未定前该能力 MUST 默认全部转人工，不擅自判定。

#### Scenario: 语义命中并给证据
- **WHEN** 判定立项依据是否说明产品"是什么"(规则 20)/"什么用途"(规则 21)、是否说明目的(规则 23)/意义(规则 24)、目标是否分类(规则 26)、指标是否量化(规则 27)、交付物与指标是否对应(规则 28)、职责与人员安排对应(规则 77)、技术总结(规则 78)/商务总结(规则 79)
- **THEN** 高置信命中 → [通过] 并附命中证据片段(引用原文)
- **AND** 高置信未命中 → 按该规则 J 列严重度判 [不合格/待改进] 并指出缺失内容

#### Scenario: 低置信转人工（不擅断）
- **WHEN** LLM 判定置信度低于约定阈值
- **THEN** 系统 MUST 标记该条为"需人工复核",不输出通过/不通过终局结论
- **AND** 该条进入审核报告"转人工待办"清单

### Requirement: 二级置信度口径对齐 SC8

系统 SHALL 使用与 SC8 一致的二级置信度口径（高 / 低），不引入未经业务确认的中间档。置信度判据 MUST 可解释、可在审计中复盘。

#### Scenario: 置信度落档
- **WHEN** 输出某条语义判定
- **THEN** 附"高"或"低"置信标签及落档依据(命中证据强度/原文是否明确)
- **AND** 低置信一律导向人工复核路径

### Requirement: 语义判定严重度遵从规则表

系统 SHALL 让 B 类规则的严重度遵从「立项门禁」J 列（如规则 26/27 为阻断、77/78/79 为一般/提示），不因走 LLM 路径而擅自升降级。

#### Scenario: 阻断级语义规则未命中
- **WHEN** 规则 26(目标分类)或 27(指标量化)高置信未命中
- **THEN** 计入阻断/错误项,影响总判定为不合格
