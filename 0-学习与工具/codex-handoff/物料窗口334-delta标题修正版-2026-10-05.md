# SC8 窗口外缺口展示规范

## ADDED Requirements

### Requirement: 页面与导出明确展示窗口外缺口范围

系统 MUST 将窗口外缺口展示为纯展示信息，并将其与窗口内三月合计区分。页面若显示 meta.out_of_window_qty，MUST 明确该值属于全量快照；不得把它描述为当前筛选结果。导出若展示筛选命中行的窗口外信息，MUST 使用该行的 r.out 或等价的行级证据，不得把全量快照值静默复制到筛选行。

#### Scenario: 快照窗口外数量与完全窗口外物料数并存

- **WHEN** 快照包含仍有窗口内缺口的物料和完全落在窗口外、因而没有展示行的物料
- **THEN** 页面分别表达全量快照窗口外数量与完全窗口外未展示物料数，并明确两者统计对象不同
- **AND** 不得把二者写成“N 个物料共 M 数量”

#### Scenario: 导出受筛选结果约束

- **WHEN** 当前筛选只命中部分展示行并生成导出
- **THEN** 导出窗口外行级信息只对应筛选命中行，并明确导出的筛选范围
- **AND** 若附带全量快照统计，必须显式标识为全量快照，且不得冒充筛选行合计

#### Scenario: 窗口内合计保持原口径

- **WHEN** 行同时具有窗口内缺口与窗口外缺口
- **THEN** 三月 total 仍仅为窗口内合计
- **AND** 窗口外数量单独呈现，并说明不计入三月合计
- **AND** 不将不同料号数量合并解释为重量、金额或齐套套数

### Requirement: 未知与零值不得混淆

系统 MUST 将缺失、空值或不含相关字段的旧快照状态表达为未知，不得用零替代；真实零值 MUST 可见。无匹配筛选时 MUST 不构造物料行，亦不得以全量快照统计暗示存在筛选匹配行。

#### Scenario: 旧快照缺少窗口外 meta

- **WHEN** 快照没有 out_of_window_qty 或相关 meta 为空
- **THEN** 页面和导出不得显示该值为零
- **AND** 若该统计被展示，必须用明确的未知状态

#### Scenario: 真实零值

- **WHEN** meta 或行级数据明确给出数值零
- **THEN** 页面或导出以可见的零值表达

#### Scenario: 无匹配筛选

- **WHEN** 筛选没有命中展示行
- **THEN** 导出不产生虚构物料行
- **AND** 不把全量 meta 作为当前筛选结果呈现

### Requirement: 保持现有页面和导出行为

系统 MUST 保持现有筛选与分页语义，导出全部筛选命中行而非只导出当前页。系统 MUST 保持既有 13 列业务顺序、日期、多值列、BOM、HTML/Excel 字符转义以及 HTML table .xls 的打包方式、UTF-8 BOM、MIME 与文件名方案。页面与导出对特殊字符和字符串数值 MUST 安全编码，不得造成脚本执行或 Excel 文本公式注入。

#### Scenario: 导出不受当前页限制

- **WHEN** 当前筛选命中多页数据且用户导出
- **THEN** 导出包含全部筛选命中行
- **AND** 既有 13 列业务顺序及字段表示保持不变

#### Scenario: 特殊字符与字符串数值

- **WHEN** 料号、名称或数量来源含 HTML 特殊字符或以公式前缀开头的字符串
- **THEN** 页面/导出按既有安全语义编码或转义
- **AND** 字符串不得执行为脚本或 Excel 公式

#### Scenario: 窗口外提示仍为纯展示

- **WHEN** 页面展示行内窗口外标签、统计提示或导出窗口外数据
- **THEN** 这些信息仅用于展示，不改变缺口计算、排序、筛选决策或业务判断
- **AND** 既有行内标签和页脚说明保持不变
