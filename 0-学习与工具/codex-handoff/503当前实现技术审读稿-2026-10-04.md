## 二、推荐的完整技术取值（待批准）

### T1：最终字节统一出件，CLI 与公共 API 同一合同

1. 保留内部纯拼装能力为私有函数。公共 `generate_opener(**kwargs) -> str` 要求 `out`，可选 `anchor`；返回**实际落盘后回读的块文本**。缺 `out` 抛 `OpenerGenError`，CLI 对应退出码 1，stdout 无块内容。
2. 完成 Codex 环境/模型/会话标识转换后，才给最终正文盖指纹、做完整自检。内部结构检查使用私有函数；不提供公开的“跳过指纹”选项。
3. `check_block` 先对原始正文检查指纹，再做现有结构适配。给 `Block` 增加带默认值的原始正文属性，保留现有三个位置参数调用；parser 保留原始正文，SHA 只归一 `\r\n`→`\n`，不丢掉空白或其它字符。
4. 指纹算法只在 lint 中实现一份，generator 沿 `_load_lint_module()` 从同目录加载。结构适配后的文字不被输出，也不作为指纹输入。
5. 子任务指令尾序保持当前各句顺序，**哨兵为最后执行指令，指纹为最后元数据行**。现有 F8–F16 内容条件保留；修改“哨兵是字节末行”的注释/契约期望，不能删哨兵来让新用例变绿。

这是公共 API 出件语义的补充，不能说成已被旧 CLI 选项批准单独覆盖。源码检索范围 `0-学习与工具` 非测试 Python 中，当前 `generate_opener` 命中为自身定义与自身 CLI 调用；该范围的检索不代表其它目录或仓库外无调用方。实施前要复核受影响调用方。

### T2：完整署期与可证明的存量豁免

推荐指纹尾行：

```text
〔出件指纹 ab12cd34 · 出件日期 2026-10-04 · 由 工具-opener生成.py 出，勿手改〕
```

这里的日期只是**格式实例**；实际值由出件调用时取得，不能固定为本稿日期。尾行本身仍排除在正文 SHA-256 计算之外。

1. 新指纹尾行增加完整 ISO 日期；原先的“块内最后一行、SHA-256 前 8 位”保留。MMDD 不再独立提供年份证据。
2. 生效日仍是**实际实施落地日**。落地前在隔离工作树形成一次经审阅的存量清单，包含路径、原块标识、正文完整 SHA-256、所依据的日期证据和 source HEAD；不收录无证据项，不给手打件补盖生成证明。
3. 既有 H1–H3 历史判据继续由正本判定；历史取证失败仍为 unknown-history，不能默认为历史。
4. 当前在用件没有指纹时，只有命中经审存量清单且正文仍与记录逐字节一致，才可豁免；新块、复制到新载体的块、或被修改的块须经生成器重新出件。缺证据项显式报迁移缺口，不猜年份。
5. 已有指纹时，校验尾行格式、数量、位置、日期可解析和正文摘要；有意识伪造仍属于原设计已明确的残余风险，不能宣称指纹证明密码学身份。
6. 建议存量清单为一份**明确跟踪且经审的迁移配置** `0-学习与工具/opener指纹存量豁免.json`，不放 `reports/`，不在运行期自动扩张。结构字段固定为 `schema_version=1`、`source_head`、`effective_date`、`entries[]`；每项为仓库相对路径、块标识、正文 SHA-256 和日期证据。文件尚未创建。

**这会收紧原③-1的细则**：旧稿允许落地日前编号的当前件长期无指纹；推荐方案只保留可取证且未变化的旧块豁免。增加完整署期及迁移配置也增加交付面。此处明确待本人批准，不能借四项历史 (a) 默认为已批。

若不批准该收紧，原③-1仍保持原批准状态；当前完整年份判定必须获得其它可验证方案后才能实施，不能按 MMDD 猜测或回填假日期。

### T3：落盘原子性、锚与输出边界

1. `out` 为批准工作树内的相对 `.md` 路径；路径归一后逃出工作树、经链接指向外部或命中队列真身/归档/行日志时拒绝。受保护的派单/接力文档仍先走现有锁，不能用新 API 绕开共享文档纪律。
2. 不传 `anchor`：新文件写单块；已有文件仅在它是同一编号的单块出件时替换。已有混合正文要求显式锚，不整份覆盖。
3. 传 `anchor`：匹配围栏外唯一的完整章节标题；不存在或重名即报错。章节内同号块唯一时只替换该块，没有同号块时插入；有多个同号块则报歧义。其它正文原字节保留。
4. 先完成路径、锚、现有文件和块自检，再同目录写临时件、原子替换、从目标回读具体块字节，确认与拟写块一致后才出 stdout。真实 CLI 写 UTF-8 字节，不能多打一行由 `print()` 产生的换行。
5. 写入/回读/替换任一步失败均非零退出、stdout 无块；失败清理只触碰本次创建的临时件。不得回滚掉并发作者的修改。
6. 两份旧批处理器当前读出件文件并产生自己的进程日志；主仓限定两文件检索 `rg -n 'opener生成|generate_opener|--op-id|stdout|OpenerFile' '0-学习与工具/工具-opener批处理执行.ps1' '0-学习与工具/工具-opener批处理执行v2.ps1'` 未发现直接生成器调用。实施前重核，只有实际消费者需要适配。Codex 不启动这些脚本的 Claude 后台。
