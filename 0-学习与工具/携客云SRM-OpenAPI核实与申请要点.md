# 携客云 SRM OpenAPI —— 核实与申请要点

> 用途：发给携客云客户成功/对接人 + 公司 IT，解除 SC8 对客上线的 SRM 阻塞。
> 背景一句话：SC8（客户订单交期智能承诺）需从携客云 SRM 实时读取**供应商承诺交期**来推算并通报客户交付日；当前用真实凭据调 API 返回 **900401「企业未开 OpenAPI」**，对客上线被硬阻塞。
> 企业账号：59578100　｜　日期：2026-06-11　｜　提出人：Paul（供应链 VP）

---

## 一、当前现象

- 用真实凭据访问携客云 SRM OpenAPI，返回错误码 **900401：企业未开 OpenAPI**。
- 影响：拿不到供应商承诺交期（vExpectedDate），SC8 交付日预测无法基于真实交期，**不能对客上线**（FO 客户订单 + BOM 已接通，仅 SRM 这一路断）。

## 二、需先核实的冲突点（给 IT / 内部）

> 早期试点（supplychain）记录显示"SRM 已接通、读到过真实承诺交期"，与现在 900401 冲突。先内部查清：

- [ ] 早期试点当初是**通过什么通道**拿到 SRM 承诺交期的？（OpenAPI / SQL 只读直连 / 文件导出 / 其他企业或测试账号）
- [ ] 若当初不是走 OpenAPI，那条通道现在**是否仍可用、能否合规复用**于 SC8？
- [ ] 现用企业账号 59578100 与早期试点账号**是否同一个**？

## 三、给携客云的申请诉求

- [ ] 为企业账号 **59578100 开通 OpenAPI** 访问权限。
- [ ] 提供：API 凭据（AppKey/Secret 或等价）、接口文档、鉴权方式。
- [ ] 确认读取**供应商承诺交期**的具体接口与字段（含 vExpectedDate 或对应字段名）。
- [ ] 确认**调用频率限制**（限流规则、配额），便于我方做退避。
- [ ] 是否提供**沙箱/测试租户**，供对客上线前做真实联调。
- [ ] 预计**开通周期**（关键路径，影响 SC8 对客上线排期）。

## 四、给 IT 的协同事项

- [ ] 牵头/协助提交 OpenAPI 开通申请，明确公司侧审批与对接人。
- [ ] 若需 VPN / IP 白名单 / 内网出口，提前准备。
- [ ] 在 FO 接口补 **customer_id**（SC8 客户数据隔离键，当前临时用客户名，customer_id 更稳）。

## 五、紧迫性说明

SRM 这一路是 SC8 **对客上线的总闸**：FO+BOM 已就绪、门禁与审计已结构性到位，只差真实承诺交期。OpenAPI 一旦开通并联调通过，SC8 即可由"内部验证"翻到"对客通报"。请按关键路径优先推进，并回告预计开通时间。
