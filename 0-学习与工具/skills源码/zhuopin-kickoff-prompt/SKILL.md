# 卓品 · 交接/转场 Prompt 生成器（v1.3）

为"企业AI转型"项目生成新 session 的交接 prompt。**铁律：引用版**——prompt 只放权威文件的路径与章节指针，绝不复制其内容（防双份漂移，Paul 2026-07-06 定为标配）。

> v1.1（2026-07-10）：收工段强制带 git 处置、prompt 呈现一律 fenced 代码块；纪律段加跨桌任务队列。
> v1.2（2026-07-16）：CC 类 prompt 必含分支/worktree 行（协议第 5 条入骨架）。
> v1.3（2026-07-17）：**开场词一律自带【设置】固定结论行**——"分支：X ｜ worktree：勾/不勾"由生成方判断完毕，Paul 照抄零判断（不再给口诀让 Paul 自己推）。

## 执行步骤

1. **判定目标线**：Cowork 域专线（采购/财务/质量/销售）｜Cowork 全景总线（重组循环执行）｜CC 建造（代码/真实库/git）。分工红线：域专线不改全景；总线不重开域口径；CC 不改规划文档。
2. **收集指针**（只收路径，不抄内容）：本次任务的权威依据（移交单/局部定稿/需求件/执行单）+ 对应接力文件（`1-转型规划/session接力-<域>场景落地.md` 或 `0-全景路线图/session接力-Phase1收口.md`）+ 根 CLAUDE.md。
3. **写 prompt 文件**，命名 `开场prompt-<主题>-<目标线>交接.md`，落位：总线/重组类入 `1-转型规划/0-全景路线图/`，域专线类入 `1-转型规划/`。frontmatter 必含 title/created/执行方/来源/status: 待执行。
4. **正文骨架**（顺序固定）：
   - 用法行 + **「开场词（复制即用）」**：单句、含本文件完整相对路径 + "＋CLAUDE.md 当前进度恢复上下文，按文件执行；开干前问我 2-3 个澄清"
   - 背景一分钟（≤5 行）
   - 权威依据清单（①②③… 路径+章节指针+一句话说明各是什么）
   - 任务分段（A/B/C… 按优先级，每段含验收标准）
   - 纪律段：引用 CLAUDE.md §5/§7 相关条目名（排期同步/完工即归档/§0.2 登记/对客闸/mock先行/哨兵/**跨桌任务队列——开工必读认领+登记触碰区、收工必写+下游任务当场追加**），不抄全文
   - **分支/worktree 行（CC 类必含，v1.2 强制）**：prompt 开头明示"分支＝<触碰区列的分支名>／全新独立建造＝master+新worktree"，并写"按队列协议第 5 条开工三查（worktree list/当前分支/队列行比对，不匹配即停手报告）、完工即推送"；**交付给 Paul 的开场词上方必附一行固定结论**：`【设置】分支：<名> ｜ worktree：☑ 勾选/☐ 不勾`——判断由本 skill 按口诀完成（触碰区有分支名→该分支+不勾；全新独立建造→master+勾），Paul 照抄即可，**不得只给口诀让 Paul 自己判断**（零歧义规则，Paul 2026-07-17 定）。
   - **收工段（必含 git 处置，v1.1 强制）**：滚动对应接力文件 + 更新台账状态；**Cowork 专线/总线类** prompt 收工段须写明"列出本次全部新产出/修改文件清单 + 建议 commit message + 登记队列 §二待 commit 批次 + 提示 Paul 一句话交 CC：commit + push + 收工重跑台账"（Cowork 不擅自 commit，但不留未提交悬置）；**CC 类** prompt 本含 commit+push，另加"收工重跑文档台账"。
5. **交付**：present_files 附文件卡片 + 在聊天中给出开场词可复制块。若 Paul 未说明澄清问题，替目标 session 预置 2-3 个建议澄清问题写进 prompt 用法行。
6. **呈现格式（v1.1 强制）**：聊天中交给 Paul 的 prompt/口令，**≤500 字直接给完整原文、>500 字落 prompt 文件 + 单句开场词引用**；无论长短一律放 fenced 代码块（```…```，渲染自带复制按钮），不用引号段落。

## 禁止

- 复制移交单/定稿/CLAUDE.md 的正文内容进 prompt（只给指针）
- 让 Paul 自己拼路径（开场词必须完整可粘贴）
- prompt 内设定新的业务决策（决策只在移交单/Paul 拍板里）
