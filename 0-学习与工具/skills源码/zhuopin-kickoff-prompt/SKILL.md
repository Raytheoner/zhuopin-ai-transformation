# 卓品 · 交接/转场 Prompt 生成器（v1.26，引用式收敛）

> **铁律一 · 引用版**：prompt 只放权威文件的路径与章节指针，绝不复制其内容。
> **铁律二 · 格式零复述（v1.26，2026-09-04 A2 改指骨架文件）**：**本文件不含任何 opener 的「长什么样」**——标题行、编号、`【设置】` 字段、会话名、状态标记、骨架，**唯一来源＝ `1-转型规划/0-全景路线图/opener骨架.md`**（模板库 §〇 是判据、不是格式来源）。起草前先 Read 该骨架件，复制骨架、替换占位符；**不得凭记忆或凭本文件重建格式**。历史沿革与 v1.16 全文见同目录 `CHANGELOG.md`。

## 执行步骤

1. **判定目标线与执行环境**：Cowork 域专线／Cowork 全景总线／Cowork 环境保障线／CC 建造。判别口径＝根 `CLAUDE.md` §5「执行环境标注」＋ `.claude/rules/两桌同步与取证.md` §一（只产改 `.md`＝Cowork；写跑代码／连真实库与 `.51`／部署／自行 commit＝CC；**改本机工具链＝CC**）。分工红线：域专线不改全景；总线不重开域口径；CC 不改规划文档。
2. **判定转场类别，定提问策略**（正本＝模板库 §〇.3）：A 同线转场 ⇒ opener 内置「开工自检三查」、通过即不问；B 跨线交接／C 新任务 ⇒ 必问，且预置带推荐项的选择题；D 定时任务 prompt ⇒ 🔴 绝不写任何需人当场回答的指令。数量随歧义数走，无歧义 0 个。
3. **收集指针**（只收路径）：权威依据（移交单／定稿／需求件／执行单）＋对应接力文件＋根 `CLAUDE.md`／命中的 `.claude/rules/*.md`。
4. **Read `1-转型规划/0-全景路线图/opener骨架.md`，按执行环境复制【CC】或【Cowork】骨架**，替换占位符。骨架之外只允许追加「做什么／不做什么／收工」正文；**不得改动骨架里任何一行的形状**（含 `set_session_title` 整行与子任务例外句、`session：新开`、`worktree：☑／☐`）。
5. **开工前置步写进 opener**：「开工第一件事：用 `python 0-学习与工具/工具-队列查询.py --digest`（业务场景加 `--file 1-转型规划/0-全景路线图/跨桌任务队列-业务场景.md`）扫两份队列与归档件的摘要，按触碰区关键词核无他人在办行重叠，命中再 `--row N --field all` 展开；🔴 不得 `Read`／`grep` 队列真身（K3 读侧禁通读）；有重叠不得抢领，报总线裁决。」队列协议细则一律指向队列顶部「协议〇」与 `.claude/rules/队列与落库.md`，不复述。
6. **收工段必含 git 处置**：Cowork 类＝列产出清单＋登 §二 批次（sweep 落库，不写「一句话交 CC」）；CC 类＝commit+push＋收工重跑台账。
7. **收工报告定夺项路由**：只问「答完由谁动手」——本 session 做 ⇒ ⟨就地答⟩给选项＋默认项；他人做 ⇒ 不给选项、只写「已登记 §一/§四 #N，待总线派发」。正本＝根 `CLAUDE.md` §5「决策路由」。
8. **≥2 个 opener 必附次序与并行矩阵**（正本＝模板库 §〇.8）：能否立即开工（四选一）／能与谁并行（判据＝触碰区是否重叠）／串行理由。
9. **交付**：present_files 附文件卡片（>500 字落 `开场prompt-<主题>-<目标线>交接.md`，frontmatter 含 title/created/执行方/来源/status）；聊天中一律 fenced 代码块，**代码块正上方写状态标记**（`▶ 首次派出：`／`▶ 更新版（你尚未执行）：`／`▶ 重发（你已执行过）：`，三式正本＝`opener骨架.md`，判据＝模板库 §〇.19）；重发同样带标题行。
10. **交付前自检（逐条对，缺一不发）**：
    - [ ] 骨架来自 `opener骨架.md` 本次 Read 的内容，不是记忆；
    - [ ] 六字段齐且顺序＝`执行环境｜分支｜worktree｜工作区｜session｜派出线`；
    - [ ] 首行 `[OP-MMDD-X]【CC／Cowork】<短名≤12字>`；编号同时出现在节标题与矩阵首列；
    - [ ] CC 件含 `mcp__ccd_session_mgmt__set_session_title`＋`"self"`＋`[Win]MMDDX-<短名>`＋子任务例外句；Cowork 件不含该工具调用；
    - [ ] 含「不」字的字段写清否定作用域（正本 §〇.1／v1.12）；
    - [ ] 把块写入临时 `.md` 跑 `python 0-学习与工具/工具-opener块lint.py --enforce`（形态①②；`[Win]`／六字段／首行形态的机器判据＝队列 #381 ⑸ⓖ 待落地，落地后本条改为必过）。

## 转场判据（v1.13，Shao Peishen 2026-08-19 答 (a)；本节是纪律不是格式，故留在本文件）

转场理由必须是「上下文退化的可观测行为证据」，五条逐一自查，**全阴性即不得转场**：① 忘记本会话早先确立的事实；② 重复已做过的工作；③ 前后矛盾且未标更正；④ 丢失或曲解他的指令；⑤ token 压力真实且**压缩手法用尽**（子代理承接大文件／`grep -o` 只取窗口／一次性脚本出摘要，三条都用过仍紧张）。**两条反判据**：「本会话犯了 N 次错」不是判据（被机制拦住的错证明机制在工作）；「上下文长」不是判据（先压缩、后转场）。自检一问：*能不能指着本会话里一处具体文字说「这里就是退化」？*
