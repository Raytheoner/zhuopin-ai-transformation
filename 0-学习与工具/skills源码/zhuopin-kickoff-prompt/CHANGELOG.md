- 🔴 **`【设置】` 行只声明 `worktree` 而不声明 `CC session`**（见步骤 1，v1.12）——**只写 `worktree：☐ 不新建`，那个否定会被读成「整件事都不用新建」**；更一般地，**任何含「不」字的字段都不得省略其作用域**
- 🔴 **产出要粘给 CC 的指令块却没有 `【设置】` 行**（不论该块多短、任务多小，见步骤 1 的 `【设置】` 行自检，v1.14）——**「短指令不配 `【设置】` 行」是个隐含假设，不是理由**；唯一判据是「这块要不要粘进一个 CC 会话」
- 🔴 **以「本会话犯了 N 次错」或「上下文已经很长」为理由提议转场**（见 1.6，v1.13）——**被机制拦住的错证明机制在工作，不是退化证据**；须先逐条自查 1.6 的五条可观测退化证据，全阴性即不得转场，且**压缩手法未用尽不算 token 压力**
- 🔴 **援引某一条规则为自己的决定背书，却没有把同一段的其余句子读完**（见 1.6）——**大规则集会催生合理化**，2026-08-19 与更早那次都是只取了对自己有利的半句
