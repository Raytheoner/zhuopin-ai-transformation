## 执行步骤

1. **扫池／排波**：触碰区两两比对，重叠即分波；锁工具族恒最后一波；单批上限见上「触发与前置」——**只读引用 `zhuopin-lane-clearpool/SKILL.md` 步骤 1-2 的既有实现，不把那两步的文字复制进本文件**（D2/tasks 4.3）。
2. **落档**：生成看护件（格式沿清池样板），走锁登记 §二 批次；🔴 落档失败即全停。
3. **组 opener**：每条泳道的 opener 正文，在清池既有的无头 CC 引导之外，须额外内置三句（这是本包与另两包 opener 的唯一区别）：
   - 一句指向 D1 表现取命令（`... criteria`），**不在 opener 里手抄判据表**；
   - 命中 🟡/🔴 动作时的动作指令：先跑
     ```
     python 0-学习与工具/工具-泳道看护状态机.py pause --batch <批次> --wave <波次> \
       --lane <泳道名> --action-key <D1键名> --waiting-for "<在等什么>" \
       [--option "<候选答案>"]...
     ```
     （落状态 ＋ 推「等人」企微通知一次做完，见工具的 `pause` 子命令），随后**以 `OPENER_PARTIAL: 停在<🟡|🔴>决策点——<在等什么>` 收尾**；
   - 判据未覆盖时按 🟡 停、在收尾原因里问「这个动作该进哪一档」——工具的 `classify`/`pause` 对未知 `--action-key` 已自动 fail-safe 并把提示文案带进企微通知，opener 只需照做，**不必自行判断该不该停**。
   - 🔴 **不改 `工具-opener批处理执行v2.ps1`**（tasks 4.1，只读核对结论）：该脚本只认 `OPENER_DONE`/`OPENER_PARTIAL` 两个哨兵；`OPENER_PARTIAL` 退出码 0，**不会**触发该脚本「FAIL/NO-SENTINEL 才停本泳道」的中断逻辑（脚本源码 `if ($status -like 'FAIL*' -or $status -eq 'NO-SENTINEL') { break }`），故同一泳道计划里排在暂停项之后的独立项仍会继续跑——**若后续项依赖被暂停的这一项，opener 正文须让该后续项自己先查状态文件（`... show --lane <泳道名>`），仍是 paused 就立即以同样的 `OPENER_PARTIAL` 收尾，不得盲目往下做**。
4. **起泳道**：经 `工具-opener批处理执行v2.ps1` 起无头 CC（`isolation: worktree`），调用签名/心跳/企微四类事件推送**完全不变**（4.1 只读核对，未改该脚本一行）；心跳落 `reports/lane-heartbeat/`。
5. **看护**：
   - 🟢 档：自动做完，继续下一项（同清池）。
   - 🟡/🔴 档：泳道以 `OPENER_PARTIAL` 退出，`reports/lane-watch-state.json` 已有该泳道的 `paused` 记录（跨 worktree 共享同一物理文件，见工具模块文档「跨 worktree 可见性」）；Cowork 在会话内以「需你定夺」格式呈现（根 `CLAUDE.md` §5 格式四条：编号 + (a)(b)(c) + 各自代价 + 默认项）；他回一个字母后，Cowork 跑
     ```
     python 0-学习与工具/工具-泳道看护状态机.py resume --lane <泳道名> --answer "<他的答复>"
     ```
     再据答复内容起下一段泳道（新开一次 `工具-opener批处理执行v2.ps1 -Only <该泳道下一段>` 或等价小批调用）。
   - D3：单条泳道停不影响其余；**唯一例外**——失败/暂停项在其他泳道依赖链上（触碰区重叠或产出被下游引用）时整链停。
   - 🔴 **D5 待答超时兜底**：看护轮询期间（或续跑前置检查）跑
     ```
     python 0-学习与工具/工具-泳道看护状态机.py check-timeout
     ```
     （默认 4 小时），命中即把该泳道降回原状态、写明「因超时未获答复而收回」、并入当日收工汇总；他回来仍可重新触发该泳道。
6. **收工**：汇总（每泳道一行 ＋ 心跳全文 ＋ 🔴 **D6 新增「本批停 N 次｜逐次：<泳道>／<档位>／<停在什么动作>／<他答了什么>／<等了多久>」列**——跑
   ```
   python 0-学习与工具/工具-泳道看护状态机.py summary --batch <批次>
   ```
   现取，不手工数）推企微 ＋ 落档；队列回写走锁。
