## 读取纪律（先背再动手）

- **队列类高频文件的读与写回验证一律走本机 PowerShell 直读真身**（`ReadAllBytes`/`Get-FileHash`，只读用 cmdlet 全名）——沙箱桥有缓存滞后与尾截断假象；沙箱 bash 输出里的 U+FFFD 多为管道显示假象，以 PS 直读为准（正本＝CLAUDE.md §5 直读原则、`0-学习与工具/取证方法知识库.md` §三.1）。
- 🔴 **写完必须反查落盘、不采信成功回显**（#255），且**至少配两个互不相关指标**（行数变化＋关键词命中）——反查工具自身也会静默失效（#305 族）。已验证写法：`(Select-String -Path $f -Pattern $k -SimpleMatch).Count`（**勿加 `-AllMatches`**；`-Pattern` 串**勿含反引号**）。脚本打印哨兵串，没看到哨兵就是没跑成。
- 🔴 **查主工作区脏文件用本机 git，不得用沙箱 git**（#305：autocrlf 差异会把 30+ 未改文件虚报为已改——罕见的「虚报坏消息」方向）。
- 🔴 **时间戳必判 UTC vs 本地**（本机 UTC+8；审计 JSONL＝真 UTC，mtime/计划任务/事件日志＝本地；时长用 `TotalHours` 防丢 Days）；**判「某修复是否已生效」先比修复 commit 时刻与失败日志时刻**（残留崩溃会伪装成"修了没用"）。正本＝取证知识库 §一.2/§一.3。
- 🔴 **acquire 与写盘必须两步、中间查 `$LASTEXITCODE`**（#200：「工具拒绝了」与「动作没有发生」是两件事）。
- 🔴 **判「某事是否已做」必须实测且读状态列开头**：一律 `python 0-学习与工具/工具-队列查询.py --row N`（全文不截断；头尾互斥时的冲突警告在「✅ 开头＋合规保留历史原文」上常态触发，属可接受噪声、勿据此放宽——它拦住的正是真实误判，#268）。

## 二、逐行核对：七类失真

| 类型 | 判据 | 处置 |
|------|------|------|
| ① 已完成未销行 | 产出/接力节/commit 在，状态仍"待领/在办" | 补记销行（"审计补记"+证据指针） |
| ② 状态字样过时 | 日期性措辞失效、被新事替代、引用已删文件 | 按现状重写该格，登记列加"（MM-DD 刷新）"。⚠️ 只扫标题会误判——须同时看正文（§四#35 判例） |
| ③ 到期无证据 | 红线日已过而证据夹无产出 | 升级：标 ⚠️ 过期+触发预案，§四 对应行改"立即" |
| ④ Shao Peishen 动作缺行 | 看板有"待审/拍板"状态但 §四 无行 | §四 补行 |
| ⑤ 触碰区撞车 | 待领行触碰区与在办行重叠 | 加防撞注：建议并入或同一执行方顺带 |
| ⑥ 跨分支漂移/行号撞号 | 长期分支队列副本有独立编辑史（同号不同内容） | 不得盲目"全取一边"：逐冲突核 commit hash 是否真在 master；改动在 master 真实最大号后续排；push 前 `git merge-base --is-ancestor` 核可快进 |

## 五、输出简报（聊天）

顺序固定：① 总体结论一句；② 最要紧一条置顶（通常类型③，写明今天该做什么）；③ 修正清单（每处一句：原状→改后）；④ 观察项；⑤ Shao Peishen 动作优先级——每项是非/选择题＋(a)/(b)/(c)＋代价＋默认项（默认项两前提见 CLAUDE.md §5），**提出前先 `--row` 核它还成立**。**标注规则（v1.9 更新）**：原「【总线答】/具体 session 名」已被 2026-08-19 决策路由改版覆盖退休——审计自提的项他直接在简报里答，无需标注；答完须另起 session/归他线/对外的项**不给选项**，只写「已登记 §N，待总线派发」。≥2 个可开工任务必附次序与并行矩阵（判据＝触碰区重叠，CLAUDE.md §5）。简报不落文件（队列本身即记录）。

## 六、每周清扫尾步（协议〇.8，仅周一值周巡检轮做）

顺序不可颠倒：1) **先完成全部对账修正**——否则会把"其实没完成"的行迁进归档等于永久失踪；批量过滤既误迁也误留（08-03 实测 33/70），唯一可靠是逐行判读，前提不成立就推迟清扫并如实登记。2) §一/§二/§三/§四 全部已完成行整行迁 `跨桌任务队列-归档-YYYYMM.md`（按月一档，编号永不复用）。⚠️ **刻意保留不迁**：明确"无限期搁置/保留不销行"的风险行、🛑 永久关闭行、🔒 常驻台账行（#284 形态）——迁走＝从视野消失。3) 迁完立刻回写高水位线＝迁移**前**各分区真实最大号。4) 迁移与回写同一个锁窗口。5) 简报记一句：迁走 N 行、高水位线 §一 #X／§四 #Y。（下游已适配归档件：机器人取号与哨兵同扫归档，#99。）
