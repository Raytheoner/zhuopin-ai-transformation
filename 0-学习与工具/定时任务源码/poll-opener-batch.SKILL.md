
🔴 **`--via-scheduled-task` 不能漏**：它只决定企微推送的落款写「定时任务」还是「手工运行」。漏了会把机器守报成手工，**让人以为没在跑**。


  把 Status 列里**非 OK** 的泳道单独列出来（`NO-SENTINEL`／`PARTIAL`／`FAIL(n)`）。**不要去修、去续跑、去合分支、去改队列。**

