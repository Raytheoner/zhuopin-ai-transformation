- 🔴 **读侧禁通读（K3）**：两份队列真身与归档件**不得 `Read` 全文、不得 `grep`**（一行可达 78 KB）。判行只用 `工具-队列查询.py --row N [--section 一|四] [--field all]`；扫池用 `--digest`（业务场景／归档件加 `--file <路径>`）。**行内日志外置口径**：§一 状态格／§四 事项格 ≤4 KB，超限把历史回写段迁 `…/队列行日志/#N.md`（原文原样，工具＝`工具-队列行K2外置.py`），行内留首段＋末段＋指针；回写只追加末段、不复述历史。

- 🔴 **`登记豁免：` 止血口径**（机器守＝`#416`⑶，落地前人守）：`release` 前工作区每个脏文件只有两条路——**登进 §二 批次**，或在 acquire note 里**逐个点名豁免**（`登记豁免：<仓库根相对路径>；…（作者 <OP 号>，到期 MM-DD）`）。🔴 **禁写「他线脏文件由其作者线自登」这类不点名的泛豁免**。见 sweep 孤儿告警的会话**先核 `git diff --numstat` 再代登**（只增日志与已核 diff 的留痕件可代登；载荷 `队列回写待补/*.json` 与在跑会话的件不代登）。
- 🔴 **定夺答复的落点：谁端出来的题，就在谁那儿答**：Cowork 端的在 Cowork 答，CC 端的在 CC 答；**跨端转达一律标「已答，勿重做」并写明由谁执行**。🔴 **同一题不得两端各答一次**（两端执行体互相看不见，会同时动手）。⚠️ **例外只有一个**：泳道看护批 🟡 停点恒由 Cowork 端出、只认 Cowork 侧答复（lane-watch D5）。
