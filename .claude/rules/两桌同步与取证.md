# 规则 · 两桌同步、git、取证与时间戳（从根 CLAUDE.md §5.4 迁入，2026-09-03 P2）

> CC 触碰上述路径自动加载（CC 每次开工都会碰到其中之一）；**Cowork 不自动加载，按根文件路由表显式 Read**。

## 一、两桌分工
- **Cowork（规划治理桌）＝项目总架构师**：规划／路线图／治理合规／招聘／汇报；默认只改 `.md`，Word 仅在明确要求时用 md-to-word；不碰真实库、不写生产代码。**文件链接纪律**：为他定位或产出文件一律附可达文件卡片（present_files）。
- **Claude Code Desktop（建造车间）**：写并运行场景代码、连真实 SRM/ERP、跑真实数据；不改规划文档。
- **执行环境判别**：只产改 `.md`、不写生产码、不自行 commit ＝ Cowork；写跑代码／连真实库与 `.51`／部署／自行 commit+push／一任务一 worktree ＝ CC；只读取证属 Cowork，一旦改代码或触发服务动作即转 CC；**改本机工具链（npm/插件/CLI 升级、`openspec update` 类）＝ CC**，Cowork 破例须其明示授权＋固化升级前证据＋逐文件过目 diff＋事后登记。**「已获授权」≠「该照原方案执行」**——取证推翻方案即回报改判。

## 二、git 同步
- 🛡 **机器守（CC，hook ⓐ SessionStart，2026-09-04 验活）**：开场横幅自动给出 fsck 结果、ahead/behind、本地/UTC 双标时刻与 §一待领摘要；Cowork 侧仍人守。开工 `git fsck --connectivity-only` 再 `git pull`；收工 `git push`；同一文件别两边同时改。**fsck 报错即停**，报 Shao Peishen 走恢复流程（先把未 commit 改动备份到仓库外，再重 clone，再拷回 `.env`/reports 等 gitignore 件）。**OneDrive**：平时全关、每周手动开一次作离线备份。排查「文件像是变旧了」见 `0-学习与工具/取证方法知识库.md` §三.1。
- **合并策略 ff-only**：PR 一律 ff-only，由 `工具-落库sweep.py::_reconcile_with_origin_and_push` 强制对齐；零 diff 的 PR 验证 `git log master..branch` 为空后带说明 CLOSE，不强 push、不 rebase。
- 🔴 **乱码文件夹哨兵**：CC 开工与收工各查一次上级目录，`*AI转*` 目录应且仅应 1 个（`Get-ChildItem ..\ -Directory | ? Name -like '*AI转*'`）；出现含 U+FFFD 的兄弟文件夹即停手，整树移入 `_乱码重复文件夹隔离-日期\`、逐文件哈希比对、不直删。**根因指纹**：路径与内容同现 U+FFFD；CC 写含中文路径的关键文件后，读回抽验一处中文再继续（PostToolUse 哨兵 `sentinel-mojibake.ps1` 机器守）。

## 三、取证与时间戳
- 🔴 **时间戳必判 UTC vs 本地**（本机＝UTC+8；CC 开场横幅已给双标，hook ⓐ）：引用任何时刻前先答「这是 UTC 还是本地」并显式标基准（`09:04:31Z (17:04:31 本地)`）。`wecom_aibot_audit.jsonl` 与企微告警文案＝真 UTC；文件 mtime／计划任务 `LastRunTime`／事件日志／`LastBootUpTime`＝本地。🔴 **写侧**：向队列行／批次行／`Last Updated`／接力节标题写日期，一律用本机 `Get-Date -Format 'yyyy-MM-dd'` 当场重取——不估算、不用 UTC、不写未到日期、不引用本会话早先取值、禁用沙箱 `date`；文本里出现相对表述（窗口／天数差／到期）顺手换算校验。 ⇒ 陷阱见 `取证方法知识库.md` §一.2／§一.3。
- 🔴 **工具静默回退**：一类工具参数不符预期时不报错而回退到「看起来合理」的默认行为。**判据：只读命令返回「太干净／太正常」的结果，先问它是不是根本没读到我以为的那个对象。** 已知实例（`[System.IO.File]::*` 相对路径按宿主 CWD 解析／`git -C` 向上找到祖先仓库／PowerShell 变量名大小写不敏感／混合换行符／管道末端吃掉退出码）见 `取证方法知识库.md` §二；写后反查三件套见 `专线opener模板库.md` §〇.6。同族：判本机是否重启只认 `ID=27 Kernel-Boot 引导类型`（§一.1）；**判据本身也需被质疑一次**（§四.1）。
- **直读原则**：对新鲜度敏感的读取（状态页数据层／状态核验／完整性抽验）一律本机直读（PowerShell 只读 cmdlet 全名，严禁 `rd` 等可变更别名），不用沙箱挂载副本（有文件桥滞后与尾截断假象、git 操作极慢）；沙箱 bash 只做批量 grep 与纯文本处理。状态页 Artifact＝`zhuopin-project-status`。
- **企微推送**：Cowork 写 `.md` → 对 CC 说「把 X.md 发企微」（Cowork 沙箱出网 403）。工具 `0-学习与工具/发企微.py`（读 `.env` 的 `WECOM_WEBHOOK_URL`）；底座另有 `shared_tools/notifiers/wecom.send_markdown`。
