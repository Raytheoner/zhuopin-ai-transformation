## 岗位定义卡

```yaml
# ═══════════════════════════════════════
# 数字员工岗位定义卡
# ═══════════════════════════════════════

# --- 基本信息 ---
岗位名称: 供应商风险初筛助手
所属部门: 采购部 (Procurement)
直接负责人: [采购部经理姓名]
AI 运营责任人: [AIOps 负责人姓名]
立项日期: 2026-06-01
目标上线日期: 2026-07-01

# --- 业务背景 ---
核心痛点:
  采购经理每天需要评估多家供应商资质，包括查阅工商信息、历史交付记录、
  财务健康度等，平均每家耗时 30-45 分钟。每周评估 15-20 家新供应商或续评，
  占用了大量本应用于战略谈判和供应商关系管理的时间。
期望效果:
  评估时间缩短 70%（从 30-45 分钟/家 → 5-10 分钟/家）
  人工只需复核高风险结论和边缘案例

# --- 职责范围 ---
核心任务清单:
  - 任务 1: 读取供应商工商信息（注册资本、成立年限、股权结构）
  - 任务 2: 分析历史交付数据（准时交货率、质量合格率、客诉记录）
  - 任务 3: 查询外部征信/风险数据（如有接入）
  - 任务 4: 综合输出风险评分（1-5 级）和关键风险说明
  - 任务 5: 标注评分低于阈值的供应商并触发预警通知

明确不做的边界:
  - 边界 1: 不做供应商最终准入/淘汰决策（由采购经理决定）
  - 边界 2: 不涉及价格谈判策略建议
  - 边界 3: 不处理已有合作关系的供应商深度审计

# --- 输入输出 ---
输入数据源:
  - ERP 供应商主数据
  - 历史 PO 交付记录（过去 12 个月）
  - 质量部门来料检验数据
  - 外部工商/征信 API（可选，第二个月起）
输出形式: 结构化卡片（风险评分 + 关键指标 + 说明）
输出接收方: 采购经理（通过飞书/钉钉/内部系统推送）

# --- 自动化等级 ---
自动化等级: L1（AI 建议，人决策）
说明: 第一期只做建议模式，采购经理评估时作为参考，不做任何自动决策。
      第 2 个月验证稳定性后升至 L2（AI 执行，人确认）。
```

## 可行性评估

| 维度 | 评估结果 | 备注 |
|------|---------|------|
| **业务价值** | ✅ 高频（每周 15-20 次）、耗时（30-45 分钟/次）、规则可标准化 | 供应商评分有成熟的维度框架 |
| **数据可及** | ✅ ERP 和交付数据可直接读取；征信 API 需 1-2 周对接 | 第一期只用量化指标，不依赖外部 API |
| **评估标准清晰** | ✅ 可定义"评分与采购经理最终判断一致"为正确标准 | 先跑 2 周对比验证 |
| **失败成本可控** | ✅ L1 模式下仅做建议，不产生任何业务影响 | 采购经理始终是最终决策者 |
| **合规无障碍** | ✅ 不涉及敏感数据处理 | 供应商工商信息属于公开信息 |

## ROI 预测

```
人工基准
  评估频率:        每周 15-20 家
  单次耗时:        30-45 分钟（取中位数 37 分钟）
  月耗时:          (20 × 37min) ÷ 60 ≈ 12.3 小时
  人力成本(月):    12.3h × 时薪

AI 方案
  AI 评估耗时:     3 分钟
  人工复核耗时:    5 分钟（仅复查高风险和边界案例）
  月 API 成本:     ≈ ¥200-400/月（基于 Sonnet 模型估算）
  月节省工时:      12.3h - (20 × 5min) ÷ 60 ≈ 10.6 小时

月 ROI (人工):    节省 10.6 小时 = 约 ¥3,000-5,000/月（视薪资水平）
月 ROI (效率):    评估覆盖率可从 100% 提高到 300%（更多供应商可被评估）
开发投入:        约 3-5 人天（已有数据接入的前提下）
回本周期:        第 1 个月即可回本
```

---

## 验收标准（UAT）

- [ ] **黄金用例**：准备 20 份历史供应商数据（含已知正确答案），通过率 ≥ 95%
- [ ] **边界测试**：新注册企业（成立 < 3 个月）→ 能识别并加注"建议人工重点审查"，不得直接判为高风险
- [ ] **异常输入**：数据缺失超过 30% → 提示"数据不足，评估结果仅供参考"而非强制输出评分
- [ ] **一致性**：对同一供应商重复评估 3 次，评分偏差 ≤ 1 级
- [ ] **业务方确认**：采购部经理签字确认输出可读、结论合理、可用

---

## 灰度发布计划

```
W1（仅 AIOps + 采购经理测试）
  → 5 家历史供应商回测，对比 AI 评分与人工评分
  → 偏差率 < 20% 则进入下一阶段

W2（采购团队内部试用）
  → 3-4 名采购员每人每天 2-3 家，AI 做建议，人做最终评分
  → 收集每次"一致/部分一致/不一致"标记
  → 偏差率 < 15% 则全量上线

W3+（正式上线）
  → 所有新供应商评估默认使用 AI 初筛
  → 采购经理确认或修改后提交最终评分
  → 每月 review 一次准确率
```
