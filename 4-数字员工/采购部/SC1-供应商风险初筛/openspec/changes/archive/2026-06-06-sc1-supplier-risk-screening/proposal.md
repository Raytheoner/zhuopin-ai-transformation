## Why

采购部供应商评估依赖人工逐家审查，覆盖率不足 30%，评估标准不统一，无法支撑 IATF 16949 审计追溯要求。通过 AI 辅助评估，将覆盖率提升至 95% 以上，效率提升 70%，同时建立可追溯的标准化评估体系。

## What Changes

- 新增 AI 驱动的供应商风险评分引擎，支持四维度加权评估（交付准时率 35%、IQC 合格率 30%、财务稳定性 20%、单源依赖风险 15%）
- 新增人工数据录入界面，覆盖 ERP 接口未接通阶段的 IQC 及财务数据输入
- 新增标准化风险评估报告生成器，输出 1-5 级风险等级报告供采购经理审批确认
- 新增审计日志模块，满足 IATF 16949 完整追溯要求
- SRM API（携客云）集成，自动拉取交付准时率和采购历史数据

## Capabilities

### New Capabilities

- `risk-scoring-engine`: 四维度加权评分计算，输入各维度原始数据，输出 1-5 级综合风险等级及各维度明细分
- `manual-data-input`: 人工录入 IQC 合格率、财务稳定性指标的结构化表单，ERP 接口接通后可无缝切换为自动拉取
- `risk-report-generator`: 标准化评估报告生成，包含风险等级、维度评分、核心风险描述（≤3条）、建议动作、数据来源说明
- `audit-log`: 每次评估结果写入审计日志，记录操作人、时间戳、输入数据快照、输出报告，满足 IATF 16949 追溯

## Impact

- **数据源**：携客云 SRM API（交付准时率、单源依赖）+ 人工输入表单（IQC 合格率、财务稳定性）
- **外部依赖**：SRM API 已接通；ERP（U9C）接口申请中，当前阶段跳过
- **用户界面**：CLI 或轻量 Web 表单（待定）；采购经理确认环节需签字审批入口
- **合规约束**：不向外部 API 发送供应商详细财务数据（红色数据）；所有输出为建议性意见
- **自动化等级**：L2 — AI 评估 + 风险报告，采购经理最终确认签字
