## ADDED Requirements

### Requirement: 供应商基本信息录入
系统 SHALL 通过交互式 CLI 提示，收集本次评估的供应商基本信息。

必填字段：
- 供应商名称（字符串）
- 供应商编码（字符串，可选）
- 评估人姓名（字符串）
- 评估目的/备注（字符串，可选）

#### Scenario: 基本信息录入完整
- **WHEN** 操作人输入供应商名称和评估人姓名
- **THEN** 系统记录这些信息并进入数据录入环节

#### Scenario: 必填字段为空
- **WHEN** 操作人跳过供应商名称或评估人姓名
- **THEN** 系统提示该字段必填并重新请求输入，不允许继续

### Requirement: IQC 合格率人工录入
系统 SHALL 接收操作人手动输入的 IQC 合格率数据，用于财务评分。

输入格式：百分比数值（0–100 的浮点数）或选择"数据不可用"。

#### Scenario: 有效 IQC 数据录入
- **WHEN** 操作人输入 0–100 范围内的数值
- **THEN** 系统接受该值并传入评分引擎

#### Scenario: IQC 数据标记为不可用
- **WHEN** 操作人选择"数据不可用"选项
- **THEN** 系统记录 IQC 数据来源为"缺失"，评分引擎使用默认分值

#### Scenario: IQC 输入超出范围
- **WHEN** 操作人输入负数或大于 100 的数值
- **THEN** 系统提示输入无效并要求重新输入

### Requirement: 财务稳定性指标人工录入
系统 SHALL 通过交互式提示，接收注册资本和成立年限的人工录入值。

输入字段：
- 注册资本（万元，正整数）
- 公司成立年限（年，正整数或浮点数）

#### Scenario: 财务指标录入完整
- **WHEN** 操作人输入注册资本和成立年限的有效值
- **THEN** 系统接受并传入财务稳定性评分规则

#### Scenario: 财务指标标记为未知
- **WHEN** 操作人选择任一字段为"未知"
- **THEN** 系统对该字段使用最低分，并在报告中标注"人工录入缺失"

### Requirement: 单源依赖风险选项录入
系统 SHALL 提供替代供应商状态的单选菜单，供操作人选择。

选项（五选一，与评分规则对应）：
1. 有 ≥2 家合格替代供应商
2. 有 1 家替代供应商（已认证）
3. 有潜在替代供应商（未认证）
4. 无替代供应商但已启动开发
5. 完全单源，无替代计划

#### Scenario: 选项正常选择
- **WHEN** 操作人从菜单中选择一项
- **THEN** 系统将对应枚举值传入评分引擎

#### Scenario: 未选择
- **WHEN** 操作人跳过该问题
- **THEN** 系统默认选择第 5 项（完全单源）并标注"未确认"

### Requirement: SRM 数据自动拉取与人工补录融合
系统 SHALL 优先从 SRM API 自动获取交付准时率数据，若 API 不可用或数据为空，则回退到人工录入。

#### Scenario: SRM 数据拉取成功
- **WHEN** 系统以供应商名称或编码查询 SRM API 并返回有效数据
- **THEN** 系统自动填充交付准时率，界面显示"已从 SRM 自动获取"，不要求人工录入

#### Scenario: SRM 数据不可用
- **WHEN** SRM API 返回错误或该供应商无历史记录
- **THEN** 系统提示"SRM 数据不可用，请手动录入"，进入人工录入流程

#### Scenario: 操作人覆盖 SRM 数据
- **WHEN** SRM 数据已自动填充，操作人主动选择手动覆盖
- **THEN** 系统接受人工输入值，报告中标注"人工覆盖 SRM 数据"及覆盖原因
