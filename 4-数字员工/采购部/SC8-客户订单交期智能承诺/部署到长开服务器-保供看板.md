> 与 supplychain / SalesMarketing **同一套机制**：笔记本 `sync-to-server.ps1`（SSH/scp 推送 + 重启任务）
> ＋ 服务器 `deploy-server.ps1`（建 venv + 装包 + 防火墙 + 开机自启计划任务）。组员经
> `http://192.168.100.51:8091/` 使用，无需连 Paul 笔记本。

## 端口与共存

| 项目 | 服务器目录 | 端口 | 计划任务 |
|---|---|---|---|
| supplychain | `C:\supplychain` | 8080 | SupplyChainWebServer |
| SalesMarketing | `C:\salesmarketing` | 8090 | （销售看板任务） |
| **保供看板（本项目）** | `C:\baoguan` | **8091** | **BaoguanWebServer** |

三者不同目录/端口/任务名，**同机共存不冲突**。（保供用 8091 是因为 8090 已被 SalesMarketing 占用。）

## 与那两个项目的唯一差异

AI-Transform 要装**两个包**（`zhuopin_platform` + SC8），所以服务器布局是：
```
C:\baoguan\zhuopin_platform\   ← 平台底座（sync 推送）
C:\baoguan\app\                ← SC8 工程（sync 推送，含 deploy-server.ps1）
C:\baoguan\.env                ← 凭据（手工放，不入库）
```
三源全走公网 HTTPS（FO/U9C=`erp.equalitytec.com:4443`、携客云、企微）→ **.51 只需出网，不需内网 6.x 子库**。

## 部署顺序（首次）

1. **笔记本（普通 PowerShell）** 推代码：
   ```powershell
   cd "C:\Users\Paul Shao\OneDrive\Projects\企业AI转型\4-数字员工\采购部\SC8-客户订单交期智能承诺"
   powershell -ExecutionPolicy Bypass -File sync-to-server.ps1
   ```
   （首次任务还没建，最后一步"重启"会提示失败——正常，继续第 2 步。）

2. **手动把 `.env` 复制到服务器** `C:\baoguan\.env`
   （直接拷你笔记本仓库根那份即可——两边连同一个正式库+携客云；`sync` 故意不推 `.env`，凭据不走网络）

3. **RDP 登录服务器（管理员 PowerShell）** 跑部署：
   ```powershell
   cd C:\baoguan\app
   powershell -ExecutionPolicy Bypass -File deploy-server.ps1
   ```
   建 venv → `pip install -e` 平台+SC8 → 防火墙放行 8091(LAN 全网段) → 生成 `start-baoguan.ps1` →
   注册开机自启任务 `BaoguanWebServer`(SYSTEM/重启3次) → 启动 + 健康检查。

4. **拿结尾打印的地址发小组**：
   # http://192.168.100.51:8091/

## 之后每次改动（热更新）

笔记本跑 `sync-to-server.ps1` 即可——推代码 + 自动 `schtasks /End`+`/Run` 重启任务。
（依赖有变更时，去服务器再跑一次 `deploy-server.ps1` 重装。）

## 运维速查（在 .51 上）

| 操作 | 命令 |
|---|---|
| 重启 | `schtasks /End /TN BaoguanWebServer ; schtasks /Run /TN BaoguanWebServer` |
| 前台看报错 | `powershell -File C:\baoguan\app\start-baoguan.ps1` |
| 是否在跑 | `Get-NetTCPConnection -LocalPort 8091 -State Listen` |

## 红线 / 注意

- **仅 LAN，无登录鉴权**：含**真实客户名**，**不得**端口映射/转发公网；外网开放须先加登录/Token 鉴权（待办 #10）。
- **刷新会真打三源**并把**新增 🔴 真延期推保供运维群**——正常行为，提醒组员别狂点（已串行+限流保护）。
- **对客闸 `CUSTOMER_OUTBOUND_ENABLED=False` 全程关闭**：对客改期草稿仅生成、绝不外发。
- 缓存 `app/reports/*.json` + 案例 `*.db` 含真实客户名 → 已 gitignore，留服务器本地，`sync` 不回传。
