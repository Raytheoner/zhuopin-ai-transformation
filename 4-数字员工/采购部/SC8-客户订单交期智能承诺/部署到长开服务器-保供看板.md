# 成品保供预警看板 — 部署到长开服务器（192.168.100.51）

> 目标：像 supplychain 看板一样，把保供预警看板发布到长开服务器供组员使用，组员无需连 Paul 笔记本。
> 套路照搬 supplychain `deploy-intranet.ps1`（venv + 计划任务开机自启）。脚本：本目录 `deploy-baoguan-server.ps1`。

## 前提

- `.51` 已装 **Python 3.11+**（supplychain 在跑 → 应已具备）
- `.51` **能上外网**（三源全走公网 HTTPS：FO/U9C=`erp.equalitytec.com:4443`、携客云=`openapi.xiekeyun.com`、企微=`qyapi.weixin.qq.com`）——**不需要内网 6.x 子库**
- 端口 **8090**（supplychain 用 8080，不冲突）

## 步骤

### 1. 把仓库放到 .51（二选一）

**A. git clone（推荐，便于以后 `git pull` 更新）**
```powershell
cd C:\
git clone https://github.com/Raytheoner/zhuopin-ai-transformation.git
# 若私有库需 PAT/凭据；目录可自定，下文以 C:\zhuopin-ai-transformation 为例
```

**B. SMB 复制（.51 无 git 时，照搬 supplychain 做法）**
从 Paul 笔记本用 `robocopy` 经 `\\192.168.100.51\C$` 推送，至少需要这两块 + 仓库根 `.env`：
- `5-平台底座\zhuopin_platform\`
- `4-数字员工\采购部\SC8-客户订单交期智能承诺\`

### 2. 放 `.env`（含真实凭据，不入库）

把 Paul 笔记本仓库根的 `.env` 整份拷到 .51 仓库根（同一份即可——两边连的是同一个正式库+携客云）。
关键项：`SC8_DATA_SOURCE=real`、`U9C_DATA_SOURCE=real`、`FO_API_BASE`+`FORECAST_API_KEY`、`U9C_*`、`XKY_*`、`WECOM_WEBHOOK_URL`。
（若 .env 缺失，部署脚本会生成模板，填好再启动。）

### 3. 在 .51 上以【管理员】PowerShell 跑部署脚本

```powershell
cd "C:\zhuopin-ai-transformation\4-数字员工\采购部\SC8-客户订单交期智能承诺"
powershell -ExecutionPolicy Bypass -File deploy-baoguan-server.ps1
```

脚本会：建 `.venv` → `pip install -e` 平台+SC8 → 检查/生成 `.env` → 放行防火墙 8090(限 LocalSubnet) →
生成 `start-baoguan.ps1` → 注册开机自启计划任务 `BaoguanWebServer`(SYSTEM/失败重启3次) → 启动 + 健康检查。

### 4. 发给组员

# http://192.168.100.51:8090/

- 案例处置：`http://192.168.100.51:8090/cases`
- 健康检查：`http://192.168.100.51:8090/api/ping`

## 日常运维

| 操作 | 命令（在 .51 上） |
|---|---|
| 重启服务 | `schtasks /End /TN BaoguanWebServer ; schtasks /Run /TN BaoguanWebServer` |
| 手动前台启动看报错 | `powershell -File start-baoguan.ps1`（在 SC8 目录） |
| 更新代码 | `git pull` → 重新跑 `deploy-baoguan-server.ps1`（幂等）或仅重启 |
| 看是否在跑 | `Get-NetTCPConnection -LocalPort 8090 -State Listen` |

## 红线 / 注意

- **仅 LAN 内部**：现为无登录鉴权。含**真实客户名**，**不得**做端口映射/转发到公网；外网开放须先加登录/Token 鉴权（待办 #10）。
- **刷新会真打三源**并把**新增 🔴 真延期推保供运维群**——验收过的正常行为，提醒组员别狂点（已做串行+限流保护）。
- **对客闸 `CUSTOMER_OUTBOUND_ENABLED=False` 全程关闭**：对客改期草稿仅生成、绝不外发。
- 缓存 `reports/*.json` + 案例 `reports/*.db` 含真实客户名 → 已 gitignore，留在 .51 本地。
