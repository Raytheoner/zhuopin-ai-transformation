# FI6 mock 夹具

🔴 **全部为合成数据**，单位名称与统一社会信用代码均为占位，不对应任何真实往来单位。

⚠️ **夹具刻意不含"已知异常"标注**。给 mock 数据打上"这笔是异常"的标签，等于在判据尚未
签认时先替财务部判了一遍——那些标签会顺理成章变成回归基准，判据缺口就此被绿灯盖住。
异常样本须待《异常检测判据表》签认后，由财务侧圈定真实判例（走 `CaseRecord`，`confirmed_by`
实名）再补进 `data/golden/`。

**没有 `history_baseline` 之外的历史数据是事实、不是遗漏**：「历史异常案例库」在本项目内
无既有载体（2026-09-03 实测），它须从零建。
