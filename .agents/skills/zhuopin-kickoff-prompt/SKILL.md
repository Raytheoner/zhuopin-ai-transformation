# 开场与转场指令

1. 明确本任务目标、已批范围、版本、触碰区和停点；不猜承接对象。先核分支、工作树与未知锁，保留他人现场。
2. 查询对应队列行；未指定才用digest --actionable。只携带必要规则、实际证据和后续动作，不把全部历史或长计划放入入口。
3. 给出可复制的Codex指令块，标注粘贴端，包含会话名建议、既有工作树或拟用隔离工作树、明确目标与禁项；不得声称已经改名或建好会话。
4. 同日名称用[Win]MMDD及必要后缀。标题接口须确实可用才调用，不能调用旧会话API或靠改元数据冒充界面已更新。
5. 已批任务按必要输入→实现→定向测试推进；代码收敛后跑受影响项目完整pytest及功能/audit验收。失败保留证据，不能以过滤、skip或改断言凑绿。
6. 收工写实际版本、结果、证据、未完项；共享写入按锁和§二协议。仅给出建议commit信息；无具体授权不commit/push。
