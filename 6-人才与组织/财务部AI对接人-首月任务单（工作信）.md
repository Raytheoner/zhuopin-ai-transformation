# 财务部 AI 对接人 · 首月工作信

**致 唐燕萍：**

欢迎加入公司 AI 转型。你是**财务域的第一位 AI 对接人**——我把你放在这个位置，不是要你马上写代码，而是因为接下来财务部第一个数字员工（FI1 供应链仓库对账）能不能按期上线，卡点恰恰在"对账规则到底怎么定"这件只有懂财务的人能拍的事上。这正是你的主场。

先说定位：**你 = 财务域 AI 对接人（牵头） + FI 场景前置数据/规则负责人**。从你最熟的对账和月结业务切入，边干边学 Claude Code，不急着碰生产代码。你定义清楚规则、给对了样本，AI 团队（CC/AIOps）才能把它实现准。

**你不是一个人在扛**：你牵头定规则口径、对外验收；**财务支撑团队**分担具体活——历史对账样本整理、与生产/IT 对接数据口径（收口-3/4）、ERP CSV 导出协调。下面任务里标了哪些可下派团队、哪些要拉生产/IT。请到位首周先把团队分工排一下。

下面是你到位首月（自 2026-06-29 起）要牵头的几件事，都用现成材料，不用从零摸索。

## 本月任务

### 1. 牵头 FI1 对账规则梳理 —— 差异分类口径 + L2 阈值　🔴 FI1 上线硬前提
- **做什么**：把 SMT 实际投料与 BOM 理论用量的差异，按业务实操归成几类（损耗溢短 / 来料短缺 / 管理差异 等），**写清每一类的判定边界**——这是 AI 自动归类的依据。再定 L2 人工门禁阈值：差异金额或比例超过多少必须人工确认、不自动结案。
- **为什么是你**：AI 只会照规则算，规则对不对得靠财务判断。这步价值最高，也是 CC 起 propose 的输入。
- **材料**：**首周一张纸看全 → 《FI1-对接人首周收口单（合并）》**（收口-1 规则+阈值在那，并列出 CC 还要你收的技术口径 收口-2/3/4 + 数据源 + 黄金基准）；部门级背景见《财务部场景开工就绪清单》§一。
- **双轨交付（关键）**：
  - **草案 —— 到位首周（约 7 月初）**：先出一版《FI1 差异分类规则 + L2 阈值》草案交 CC，**CC 据草案即可起 OpenSpec propose（7 月初启动规格，不必等定稿）**。草案不求完美，把大类和阈值量级先定下来。
  - **定稿 —— 7/31**：结合 CC 的 design 反馈迭代收口，作为 8 月开发与上线验收的基线。
- 这样规则梳理和 CC 的规格设计并行推进，FI1 propose 7 月初就能跑起来。

### 2. 配合拍板 SMT 投料数据源 + 选 FI1 黄金基准　🟡 数据闸 + 上线校验
- **做什么**：① 跟 IT、生产一起把 SMT 投料数据从哪来定下来（MES / U9C ERP / 还是先 ERP 定期 CSV 导出）；② 从历史里挑 1-2 份人工对账结果作"黄金基准"，AI 上线前重跑、与你当年结论对比。
- **验收**：数据源拍板（7/15）+ 黄金基准样本选定存档（8/15）。
- 这是纯财务判断活，正中你长处。

### 3. 用财务视角校准 FI1 方案 + 为 FI2 月结提前备料　🟡 把业务需求讲清
- **做什么**：① 以财务视角审 CC 产出的 FI1 方案（design），反馈对账逻辑、差异定位对不对路；② 顺手把 FI2 智能月结的三单匹配口径（发票↔入库单↔付款凭证的匹配键与容差）先在纸面上理出来——FI2 虽 11 月才上，但口径现在就能备，接口一通即上。
- **验收**：FI1 方案书面反馈 + FI2 三单匹配口径初稿（9 月底前）。

### 4. Claude Code 轻上手　⚪ 慢慢学，不急
- **做什么**：跟 AIOps 1 号学：读 CLAUDE.md（§7 红线，尤其 audit / L2 门禁 / 财务红色数据脱敏）、装环境、看懂"场景→平台底座"结构；**先不写生产代码**。
- **验收**：能看懂工作流、能用就绪清单跟踪前置；手熟后再接小代码活过渡。

## 红线（你经手财务红色数据，必须守）
- 具体金额等红色数据**按需脱敏 / 仅传聚合**，原始库数据不在 AI 侧落盘。
- 财务场景均为 **L2**：AI 自动算、你审异常，超阈值不自动结案。
- 所有对账/匹配判定写平台审计（可追溯）；OEM 隔离不适用财务（读的是供应商/ERP 内部数据）。

## 30 天成功标尺
FI1 差异分类规则 + L2 阈值定稿、SMT 投料数据源拍板、FI1 黄金基准样本选定、FI2 三单口径起头、Claude Code 基本上手。
