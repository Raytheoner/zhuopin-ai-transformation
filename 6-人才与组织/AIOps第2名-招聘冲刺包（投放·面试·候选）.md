## 一、JD 外部投放短版（招聘网站/朋友圈用，≤200 字）

> 完整 JD 见《AIOps工程师（第2名）岗位说明书》。下面是投放精简版。

**AI 数字员工工程师（AIOps）· 卓品智能**

我们是汽车 ECU Tier 1（直供比亚迪/上汽/理想），正用 AI「数字员工」重塑供应链、质量等部门的运营。你将在已验证的平台底座上，开发打通 ERP/SRM 的 AI 场景，让"齐套分析""交期承诺""8D 根因"这些活自动化跑起来。

要求：3 年+ 软件/数据工程经验，**Python 扎实**，做过 API/ERP 系统集成；有 LLM/Agent（Claude、RAG、MCP）或汽车行业（IATF/制造业 ERP）经验显著加分。

你会接触到：Claude Code + SuperPowers + OpenSpec 的现代 AI 开发工作流、真实制造业数据、从 0 到上线的完整闭环。重交付与严谨可追溯——这是汽车 AI 的底线。

> 投放渠道建议：内部转岗公告（优先）、行业垂直社区、本地制造业/软件人才库。

## 二、结构化面试计划与题库

> 与《面试打分卡》配套：打分卡是"怎么评分"，本节是"问什么、怎么排轮次"。建议 3 轮。

### 轮次设计

| 轮 | 面试官 | 时长 | 考察重点 |
|----|-------|------|---------|
| 1 初筛 | AIOps 1 号 / HR | 30 min | Python/工程基础、经历真实性、动机 |
| 2 技术 | AIOps 1 号 + VP | 60 min | 系统集成、AI/Agent、排障、代码评审习惯 |
| 3 业务+合规 | VP（Paul）| 45 min | 业务沟通、严谨/可追溯意识、合规理解、文化匹配 |

### 题库（按能力维度，对齐打分卡）

**Python 与工程素养**
- 讲一个你独立设计并交付的模块化工程，怎么分层、怎么测试、怎么和别人协作的？
- 你接手过别人写的烂代码吗？怎么读懂并安全改动的？
- 写单元测试的习惯：什么该测、什么不必测？

**API / 系统集成（核心）**
- 讲一次你对接 ERP/数据库/第三方 API 的经历：鉴权怎么做的？只读还是读写？踩过什么坑？
- 凭据怎么管理的？如果让你接一个只读 ERP 视图，你会注意什么（权限/限流/字段字典）？
- 接口不稳定/超时，你的容错和重试怎么设计？

**LLM / Agent（加分维度）**
- 用过 Claude/OpenAI API 或 RAG 吗？讲一个你做的 Agent/RAG 应用，怎么控制幻觉、怎么保证可解释？
- 知道 MCP 吗？理解"工具调用 + 权限控制"的意义吗？
- 用过 Claude Code / SuperPowers / OpenSpec 或类似 AI 辅助开发流吗？

**排障与可观测**
- 线上场景半夜挂了，你的排查路径？怎么定位是数据问题、接口问题还是逻辑问题？
- 你会给一个上线的服务搭哪些监控/告警？

**业务沟通与合规意识（VP 轮，关键）**
- 怎么跟不懂技术的采购/质量同事把一个 AI 方案讲清楚？举个例子。
- 汽车行业讲究可追溯、合规。如果业务催着上线、但审计留痕还没做好，你怎么权衡？
- 你怎么看"AI 出结果、人工确认才执行"这种门禁？会嫌麻烦吗？

### 危险信号（任一出现需谨慎）
重"炫技"轻交付/稳定；对凭据/权限安全无概念；不写测试、不写文档还觉得没必要；对"AI 必须人工把关"不以为然；沟通时只讲技术不讲业务价值。

## 三、内部候选画像与评估表

### 理想内部转岗画像

最佳人选画像（按匹配度）：**懂卓品业务 + 有软件/数据底子 + 学习力强**。具体——IT/信息化里写过 Python/做过 ERP 集成的人；或工艺/质量/供应链里"半个技术"、爱钻研自动化、做过脚本/数据工具的业务骨干。**业务理解 + 信任成本低**是内部转岗最大的优势，技术缺口可在 onboarding（30-60-90）补；但 Python 工程基础与学习力是底线，不能为"懂业务"牺牲。

### 内部候选快速评估表

| 维度 | 权重 | 1分（弱） | 3分（合格） | 5分（强） |
|------|:---:|----------|------------|----------|
| Python/工程基础 | 高 | 仅会脚本 | 能独立写模块+测试 | 工程化扎实、带过小项目 |
| 系统/数据集成 | 高 | 没接过 | 接过 API/数据库 | 做过 ERP/MES 集成 |
| 业务理解（卓品） | 中 | 不熟 | 懂本部门 | 跨部门流程都熟 |
| 学习力/自驱 | 高 | 需推着走 | 能独立学 | 自学能力突出 |
| AI/Agent 经验 | 加分 | 无 | 用过 LLM | 做过 RAG/Agent |
| 合规/严谨意识 | 中 | 随意 | 有意识 | 主动可追溯 |

> 用法：内部候选先用本表快筛（Python 基础或学习力 <3 分慎入），过线者进正式三轮面试 + 打分卡。转岗动员话术见《AIOps招聘-面试打分卡与转岗动员话术》。
