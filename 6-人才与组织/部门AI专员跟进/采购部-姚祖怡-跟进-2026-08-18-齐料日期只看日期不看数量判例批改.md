# 姚工，你上次举证的 `F02N.0224`，我们查到根子了——但它和上一个问题不是一回事

（采购部跟进信第 16 封 · 判例批改包）

## 一、先说结论

你 8 月 12 号提的第 2 个问题——**`F02N.0224` 齐料日期显示 11-18、你核定应该是 12-25**——我们查完了。

**它和「可齐套套数恒为 0」那个问题不是同一个毛病**，所以我们没有顺手一起改，单独拿出来问你。

**根子是一句话**：**我们算齐料日期时，只看了「最早的那个答交日期」，完全没看那一笔答交了多少数量**——哪怕数量是 **0**，也照样拿它当齐料日。

## 二、判例（真实数据，取自当日看板）

以你举证的那个瓶颈物料 **`R01I.0622`** 为例，它在供应计划看板上的逐笔答交是这样的：

| 答交日期 | 答交数量 |
|---|---|
| 2026-08-20 | **0** |
| 2026-09-20 | 0 |
| 2026-10-20 | 0 |
| 2026-11-20 | 0 |
| 2026-12-20 | 0 |
| 2027-01-20 | 0 |
| 2027-02-20 | 0 |
| **2027-05-20** | **10000** |
| 2027-06-20 | 0 |

**⇒ 真正有货的只有 2027-05-20 那一笔（10000）。而我们的程序采用的是 2026-08-20 那一笔——数量为 0 的那个。**

> ⚠️ **一处如实说明**：你举证时看到的是 11-18 / 12-25，我们现在实测到的是 08-20 / 2027-05-20，数字对不上——**因为预测订单和供应计划看板每月自然滚动，中间隔了几天**。**毛病是同一个，而且现在这一版更极端。**

## 三、一个规则确认（本信唯一要你想的地方）

你 8 月 18 号给我们的那三条规则，讲的是「**无答交**」的料怎么估齐套日期。

**但这次这一类是第四种情形——有答交记录，只是数量是 0。** 你的三条规则里没有覆盖它。

**我们的理解是**：

> **「有答交记录但数量为 0」应当等同于「没有答交」处理**——即走你规则 2 那条（从此刻起推 90 天），而不是把那个 0 数量的日期当成齐料日。

**这样理解对吗？** 对就回「对」，不对请给一句更正。

## 四、一件请你先知道的事（不用回）

**改齐料日期会连带动四色判定。** 因为红/橙/黄/绿是拿齐料日跟出货日比出来的——齐料日一变，颜色就会变。

所以我们**不会先改了再告诉你**：等你把上面批完、规则确认了，我们改完会把**修复前后的数字对照**和**黄金基准重跑结果**一起发给你，你看过再算数。
