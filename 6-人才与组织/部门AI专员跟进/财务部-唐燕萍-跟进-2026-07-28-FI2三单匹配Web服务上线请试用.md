# 唐燕萍，FI2 三单匹配的 Web 入口上线了，请你和李姣龙试一下

## 一、地址和能做什么

**http://192.168.100.51:8094/**

不用等 9 月正式启用——round-1 真实数据验证（10/10 料品完全匹配、零假阳性）已经证明匹配逻辑靠谱，我们先把一个能自助跑账的网页界面搭起来，让你们随时能看真实报告，不用等我们跑完再转给你们看。

打开就是一个表单，选数据源、填个 AP 单号或供应商代码，点一下就出报告，六段式：

1. 总判定（多少料品完全匹配 / 差异待复核 / 单价超差）
2. 完全匹配明细（AI 建议通过，但没有过账，可抽查）
3. 需人工确认明细（差异/待人工，如实标注，不会假装已经判完）
4. 金额微差自行消化明细（整单差异很小的那批，不转人工）
5. AP-PO 单价强制比对结果（附当前容差口径说明）
6. 孤立发票 + 审计留痕

## 二、三种数据源，如实说清楚各自的限制

- **mock（演示）**：内置的假数据，一点就能看，纯粹为了让你们先摸一下界面长什么样，不是真实业务。
- **csv（应急桥接）**：就是 round-1 我们用的那套办法——真实 PO/AP 快照 + 人工誊录的发票，能出真实报告，但目前发票这块还得我们手工准备数据放好路径，你们暂时还不能自己上传。
- **u9c（真实直读）**：能自己填 AP 单号/供应商代码直接连真实系统查 PO/AP，但发票这一段目前系统还没通（还在等 OCR，队列 #59 跟催中），点这个会如实报错，不会装作查到了。

**说明白这点是怕你们点了 u9c 模式看到报错以为坏了——这是预期内的，不是 bug。** 现在最实用的是先看 mock 摸清界面，真实数据我们仍按老办法（真实快照+人工誊录）跑给你们看，这块打通了 Web 会第一时间告诉你们。
