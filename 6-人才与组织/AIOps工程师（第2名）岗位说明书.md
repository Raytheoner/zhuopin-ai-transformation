# AIOps 工程师（数字员工开发与运维）

> 本岗是卓品智能 AI 转型项目的 **P0 关键岗位**。当前 AIOps 仅 1 人，单人服务 6 部门 20+ 场景在工程上不可行；本岗到位是 10 月六部门全面铺开前的硬前提。岗位侧重**开发与集成**（Phase 1 的瓶颈在交付吞吐），同时覆盖运维与部门对接，可按团队实际在"开发重/运维重"之间微调。

## 一、岗位概述

负责把公司各部门的业务流程，用 AI「数字员工」的方式落地、上线并稳定运行。具体是在已有的 `zhuopin_platform` 平台底座上，开发供应链/质量/财务等场景的数字员工（Skill），打通 U9C ERP、携客云 SRM 及外部数据接口，保障审计可追溯与 OEM 数据隔离合规。

## 二、核心职责

1. **数字员工开发**：按 OpenSpec + SuperPowers 工作流，开发并交付各部门场景（如 SC2 采购周报、FI2 三单匹配对账、Q2 8D 不良分析）〔🔴 2026-08-21 v7：原举例 Q1 客诉分流已下架、FI1 已条件复启暂缓，故换成两个在建场景〕，优先编写测试用例，确保可追溯、可回滚。
2. **数据接口集成**：开发与维护 MCP 只读连接器——U9C ERP（用友开放平台 OpenAPI，已在 supplychain 项目验证可读）、携客云 SRM、芯片/物流等外部 API；负责与 IT/DBA 对齐只读视图与数据字典。
3. **平台底座建设**：参与 `zhuopin_platform` 共享组件开发（审计 audit、OEM 隔离 data_isolation_layer、文档解析 doc_parser、工具编排 mcp_orchestration）。
4. **运维与可观测**：维护已上线数字员工的稳定运行（目标可用率 ≥ 95%），搭建成功率/人工介入率/Token 消耗/SLA 看板，处理线上问题与回滚。
5. **合规落地**：保证每个场景满足 IATF 16949 审计留痕、OEM 客户数据隔离、ISO 26262 人工审查门禁；维护审计日志完整性。
6. **部门对接与赋能**：作为 AI 对接人辅导各部门 AI Champion，收集需求、沉淀失败案例库，推动数据就绪度评估。

## 三、任职资格

**硬性要求**
- 本科及以上，计算机/软件/自动化/电子等相关专业；3 年以上软件开发或数据工程经验（特别优秀者可放宽）。
- 熟练 **Python**（能独立完成模块化工程、写单元测试、用 Git 协作）。
- 有 **API/系统集成**经验：调用过 REST/OpenAPI、对接过 ERP/数据库（SQL 只读取数），理解只读/最小权限/凭证管理。
- 具备工程素养：可读懂并维护他人代码、会写清晰文档、有版本管理与代码评审习惯。
- 学习能力强、能独立排障，能在与 IT/业务的协作中把模糊需求落成可交付方案。

**加分项（具备其一即显著加分）**
- 用过 **LLM/Agent 开发**：Claude / DeepSeek / OpenAI API、RAG（向量库如 Chroma）、MCP、Prompt 工程。
- 用过 **Claude Code / SuperPowers / OpenSpec** 或类似 AI 辅助开发工作流。
- 熟悉**用友 U9C / ERP** 数据结构，或有制造业 ERP/MES/SRM 集成经历。
- 了解**汽车行业合规**（IATF 16949 / ISO 26262 / APQP / PPAP）或在 Tier 1/2 供应商工作过。
- 有数据管道、可观测性（日志/监控/告警）、轻量运维（容器/调度）经验。

**软技能**
- 业务沟通能力：能跟采购/质量/财务的非技术同事把事说清。
- 责任心与交付意识：对"上线后稳定运行"负责，而不仅是写完代码。
- 注重严谨与可追溯——这是汽车行业 AI 的底线，不是锦上添花。

## 四、上手路径（30 / 60 / 90 天）

为"加快进程"设计的成功标尺：

- **30 天**：完成环境与工作流上手（Claude Code + 平台底座 + OpenSpec/SuperPowers）；跟做 SC1 上线收尾；独立完成 U9C-MCP v0.1 只读连接器联调（接口就绪后）。
- **60 天**：独立交付 1 个数字员工场景（如 SC2 采购周报或 FI1 仓库对账），通过测试与真实数据验证；建立基础运维看板。
- **90 天**：稳定运行 2-3 个场景（可用率 ≥ 95%）；作为对接人支持 1 个新部门启动；沉淀可复制的「数字员工入职 SOP」。

## 五、衡量标准（与项目 KPI 对齐）

- 数字员工可用率 ≥ 95%（技术指标）。
- 按期交付场景数 / 季度。
- 审计日志完整性与合规检查零重大缺陷。
- 部门满意度（对接的业务方"有用率"）。

> 注：按全景规划 KPI 红线，不以"AI 节省工时"直接与个人薪资挂钩，避免员工隐瞒效率提升。

## 六、协作关系

- **汇报**：VP（业务方向）/ IT 负责人（技术与权限）。
- **协作**：现有 AIOps 工程师（分工开发/运维）、各部门 AI Champion、IT/DBA（数据接口）、法务（数据共享条款/合规）。
- **工具**：Claude Code、SuperPowers、OpenSpec、Git（GitHub 私有库）、U9C/SRM/MCP。
