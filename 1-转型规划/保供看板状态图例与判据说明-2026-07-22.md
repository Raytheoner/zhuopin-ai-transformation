# 保供看板状态图例与判据说明（2026-07-22）

供姚祖怡团队核对看板结论时对照使用。**本页只做说明，不改任何判据口径**（问题 5/11 均为判据澄清诉求，非取数 bug）。

## 一、四色判据（问题 11：颜色/状态含义）

看板不存在字面叫"需备料"的状态——四色状态如下（若姚看到的是别的措辞，请截图指出具体位置，我方核对是否为下方某状态的另一种表述）：

| 图标 | 名称 | 判据 |
|------|------|------|
| 🔴 | 真延期 | 存在**已有真实供应商承诺**（携客云答交）的子件，其承诺到货日晚于计划出货日 **>3 天** |
| 🟠 | 待催 | 无真延期信号，但存在**供应商未答复**（无携客云承诺记录）的子件——齐料日无法确定，需催供应商答交 |
| 🟡 | 偏紧 | 已有真实承诺的子件，其到货日晚于计划出货日 **1-3 天** |
| 🟢 | 按期 | 全部子件均有真实承诺，且齐料日 ≤ 计划出货日 |

补充规则：
- 分级**只看"已有真实承诺"的子件缺口**，剔除"无答复"估算——即便同时存在未答复子件，只要有一个已确定承诺的子件已经延期，也优先判 🔴（确定信号优先于不确定信号）。
- 卡片上"可齐套 X / 订单量"徽标（C-2 功能）是**现货净额**辅助信息，**不参与**四色判定，只在建议动作里附加"可先齐 X 套"的提示。

## 二、"无答复"子件的齐料日估算依据（问题 5：预计齐套依据）

姚问："R02A.0019 无净额库存、无 SRM 答交，7.28 预计齐套依据是什么？"

对**没有携客云承诺交期**的子件，系统按启发式估算到货日：

```
估算到货日 = max(计划出货日, 今天) + 30 天（无反馈提前期，NO_FEEDBACK_LEAD_DAYS，Paul 2026-06-22 定）
```

即：这类子件**没有真实承诺依据**，30 天是历史经验兜底值，仅供参考排期，**不是确定交期**。这正是该子件所在成品会被归入 🟠 待催（而非 🔴/🟢）的原因——系统明确知道这只是估算，不当作"确定齐套"来对客/对内承诺。若某成品卡片显示"预计 X 月 X 日齐套"但瓶颈子件是这类无答复料号，应理解为"**按经验估算**，实际以催回的供应商承诺为准"，而非系统已确认。

## 三、"现货净额"参与判定的口径（补充，涉及问题 2/5 的库存维度）

- 现货净额开关（`SC8_NET_INVENTORY`）打开时，系统统计**卓品自建库存接口 6 个白名单仓**（WW01/ZP01/ZP21/ZP22/ZP02/ZP23，2026-07-05 Paul 定稿）的可用库存（ERP 口径 `AvailQty`，已扣预留）。
- 现货可用量 **≥ 该子件毛需求**时，视为已齐、退出待催/瓶颈判定；不足则仍按到货估算参与齐料日计算。
- 6 个白名单仓中含"委外仓"类型仓位——若姚认为委外仓库存不应计入"随时可用现货"（例如委外料需先经内部流转才能上线），这是**口径问题**，非取数 bug，请明确是否需要调整白名单，我方按新口径改造。

## 四、部分齐套 / 可齐套套数（问题 3 关联，仅说明现状）

卡片"可齐套 X / 订单量"含义：全部直接子件中，**逐个**计算 `现货可用量 ÷ 单机用量` 取整，取**最小值**作为可齐套套数（木桶效应，一个子件不够就拉低整体）。含替代料的料位，可用现货 = 主料 + 组内全部替代料现货合计（等价合并）。该数字**不改变四色判定**，只是辅助参考。
