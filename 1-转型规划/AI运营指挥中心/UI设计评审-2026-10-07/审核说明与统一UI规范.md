## 统一信息架构

桌面左侧固定导航：门户首页、应用目录、我的待办、系统与发布。业务结果置于统一内容区，用面包屑、来源链接和返回入口说明当前位置。每页一个主要动作；“进入人工复核”与普通“查看依据”区分层级。

移动采用上方当前位置与底部入口/应用/待办/系统四项。侧栏关闭后退出可聚焦区域，展开按钮同步aria-expanded；关闭侧栏及Escape可返回触发按钮。底部当前项提供aria-current。上传、大表格和批量动作优先桌面；移动重点查看结果与完成单项人工复核。

## 异常状态及数据语义

| 状态 | 用户表达 | 动作 |
|---|---|---|
| 加载 | 正在加载演示快照 | 保留导航及页面上下文，减少运动 |
| 空数据 | 暂无符合条件记录 | 调整筛选或恢复演示；不是接口失败 |
| 失败 | 演示加载失败 | 模拟重试；不暗示已向生产发请求 |
| 数据陈旧 | 显示旧更新时间，提示承诺不能据此确认 | 恢复演示快照；真实刷新与重算分开 |
| 权限不足 | 当前角色无查看权限 | 引导管理员核验；不默认扩大权限 |
| 待确认 | 资料或业务口径待人工确认 | 先补资料/人工复核，不能自动结案 |
| 试点 / 内部试用 | 在入口和页头标能力阶段 | 不等同正式业务验收 |
| mock / 规划 | 全局模拟说明及局部标签 | 规划无可执行操作；模拟执行仅本地反馈 |

状态选择器只用于设计预览。应用到项目时去除该工具，保留真实状态反馈。原型没有fetch、XHR、业务WebSocket、远程字体或跨域业务请求；Vite开发HMR仅为本机预览。无凭据、真实OEM数据或真实人员资料。
