# FI4 / FI5 价值验收指标（D-4 两级验收）

> **三级把关（因 D2 分期 L3→L4）**：① **上线验收**（能不能上，L3 建议阶段的准确性 + 合规门禁）；② **L4 晋级门**（自动拦截/过账开关能不能开——查准/查全达标才升）；③ **3 个月价值验收**（值不值得规模化）。目标值**锚定专员外部文档已写的预期价值**（下表"专员目标"列），Paul+对接人定档后回填 openspec proposal。
>
> **baseline 纪律不变**：价值验收全靠和"AI 之前"比，底数须在上线前采（FI4 ~9 月、FI5 ~10 月）——见末节。

---

## 一、FI4 三单匹配

### 1.1 上线验收（L3 建议阶段，硬门禁）

| # | 指标 | 定义 | 建议目标 |
|:-:|------|------|---------|
| G1 | OCR 字段准确率 | FI4-A 关键字段（物料码/数量/单价/金额/税率/发票号）识别准确率 | ≥ 98%（数据准备前提） |
| G2 | 明细行匹配准确率 | AI 四维匹配 vs 人工黄金样本一致率 | ≥ 95% |
| G3 | **明细错位检出率(recall)** 🔴 | 黄金样本里"总额对明细错"的案例，AI 标出比例（成本失真根源，最关键） | ≥ 98% |
| G4 | 数据完整率 | FI4-A 凑齐三单后的单据完整率 | ≥ 98%（基线 80-85%） |
| G5 | 审计完整性 | 每笔判定/退回有 audit + hash-chain 通过 | 100% |
| G6 | 财务红色数据脱敏 | 原始单价不落 AI 侧 | 通过 |

### 1.2 L4 晋级门（升自动过账/拦截前）

匹配查准率(precision) ≥ 建议目标（如 90%）**且** 明细错位查全率 G3 ≥ 98% **且** 连续 1-2 个对账周期误判可控 → 方可把 FI4-B/C/D/F 从 L3 升 L4。

### 1.3 价值验收（3 个月后）

| # | 指标 | 专员目标（锚定） | 对比基准 |
|:-:|------|---------------|---------|
| V1 | 数据准备工时 | 30-40 分/天 → 5 分/天 | baseline |
| V2 | 明细行匹配工时 | 2-3 小时/天 → 15-20 分/天 | baseline |
| V3 | 审核量压缩 | 财务仅审异常，审核量压缩 ~95% | baseline |
| V4 | 匹配成功率 | 85-90%（剩 10-15% 合理异常） | — |
| V5 | 成本失真规避 🔴 | 检出并纠正"总额对明细错"笔数/影响金额 | baseline 漏检 |
| V6 | 误报率（反指标） | AI 报异常但人工判正常 ≤ 15% | — |

## 二、FI5 付款申请自动校验

### 2.1 上线验收（L3 建议阶段）

| # | 指标 | 定义 | 建议目标 |
|:-:|------|------|---------|
| G1 | 三单状态前置校验准确 | FI5-A 判"可付/不可付" vs 实际配票状态一致 | ≥ 98% |
| G2 | 重复付款检出率 | FI5-C 检出重复/超额（含跨期、分次付款场景） | 人工 ~50% → >99% |
| G3 | 账户比对拦截准确 | FI5-B 户名/账号/开户行不一致拦截准确率 | ≥ 99% |
| G4 | 误拦率（反指标）🔴 | 合法付款被误拦 / 拦截总数（L3 阶段测，决定能否升 L4） | ≤ 占位（越低越好） |
| G5 | 审计 + 紧急特批通道 | 每次拦截/放行留痕；三单未匹配紧急付款走 CFO 审批可用 | 100% / 通 |

### 2.2 L4 晋级门

重复付款/账户/超合同检出查准达标 **且** 误拦率 G4 ≤ 阈值 **且** 紧急特批 SOP 跑顺 → 升 L4 自动拦截。

### 2.3 价值验收（3 个月后）

| # | 指标 | 专员目标（锚定） | 对比基准 |
|:-:|------|---------------|---------|
| V1 | 付款退回率下降 | ↓ 80%+（申请前就知能不能付） | baseline 退回率 |
| V2 | 重复/超额付款拦截 | 拦截笔数/金额；检出 >99% | baseline 漏检 |
| V3 | 账户错误 | 打错账户 → 系统拦截，趋零 | baseline |
| V4 | 长账龄预付款 | ↓ 50%+（FI5-E 催票+账龄预警） | baseline 长账龄 |
| V5 | 审批效率 | 仪表盘一屏看全，审批效率 ↑ 60%+ | baseline 审批耗时 |
| V6 | 误拦率（反指标） | 稳定低位，不伤现金流/供应商关系 | — |
