# FI1 ERP 投料/产出 CSV 导出需求

**致：[IT负责人] / [生产/PMC 接口人]**　**发起：Paul**　**日期：2026-06-29**

## 一、背景（一句话）

FI1 供应链仓库对账的 AI 引擎已跑通（mock）。要做真实小样本验证，需要从 U9C ERP 拿两类真实数据：**工单产出（完工入库）** 和 **工单投料（领料）**。U9C 这两个对象走 `CommonEntity/Query`、**外网当前 404**（仅 BOM/Query、FO/Query 开放），故过渡期请按下表**定期导出 CSV**（已授权的应急路径）；BOM 理论用量 AI 侧已能直读、不用导。端点开放后切实时直读、不改逻辑。

## 二、需要导出的两张 CSV（字段贴 U9C 语义，便于后续切实时零改）

**表 A · 工单产出（完工入库）** — 对应 U9C 实体 `UFIDA.U9.MO.MO.MO`

| 字段 | U9C 语义 | 说明 |
|------|---------|------|
| 工单号 | MO.DocNo | 关联键 |
| 成品料号 | MO.ItemCode | |
| 完工入库数量 | **MO.FinishedQty** | 对账期理论用量的乘数 |
| 完工日期 | MO.FinishDate | 用于归对账期 |
| 对账期 | （期间标识，如 2026-08） | 跨月在制如何归期请生产注明口径 |

**表 B · 工单投料（领料过账）** — 对应 U9C `MOPickList`（领料/发料）

| 字段 | U9C 语义 | 说明 |
|------|---------|------|
| 工单号 | 关联 MO.DocNo | 与表 A 对应 |
| 子件料号 | ItemCode | |
| 实际领料数量（净额） | 领料过账数量 **扣退料冲减** | 对账"实际"侧权威源；请注明是否已扣退料 |
| 过账日期 | PostDate | |
| 单位 | UOM | |

> 口径以《FI1-对接人首周收口单》收口-3（产出/完工口径）、收口-4（实际投料取哪条记录）的最终确认为准——本表先按 CC 临时口径（完工入库 + 领料过账净额）出，确认后微调字段即可。

## 三、范围与频率（先小样本）

第一，**先给小样本**：挑 1-2 个成品料号 / 工单，覆盖 1 个对账期（如 2026-08），让 CC 跑通真实链路即可，不必全量。第二，**对账期定期导出**：验证通过后按月（对账周期）定期导出到约定目录。第三，**格式**：UTF-8 CSV，表头用上表字段名；表 A / 表 B 各一文件。

## 四、给谁、怎么用

导出文件放约定目录，CC 用 `python -m fi1.run --data-source csv --csv-dir <目录>` 跑真实小样本。AI 侧只读、不回写 ERP；金额等红色数据**不需要**（FI1 对账以数量为主，金额脱敏）。
