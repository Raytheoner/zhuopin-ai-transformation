# 企微监听服务迁 Mac mini · 设计方案

> 一句话:**收件口从"会合盖的笔记本"迁到"长开 Mac mini",丢件风险清零;笔记本降级回纯开发客户端。迁移只动"服务住在哪",不动业务逻辑与两道门禁。**

## 一、目标架构

```
专员企微 ⇄ 企微云 ⇄ Mac mini 常驻监听(launchd)
                        ├─ 归档 → Mac 仓库副本 7-外部文档/(gitignore,本地敏感层)
                        ├─ 追行 → 队列.md → git push GitHub(bot 身份)
                        ├─ 转发 Paul 私信 / 部门群回执(企微云,人在哪都收到)
                        └─ gap_alert / 对账哨兵(照旧)
Paul 笔记本(开发) ⇄ GitHub(队列/代码同步) ⇄ 回 LAN 时单向拉平 Mac 的 7-外部文档
```

Paul off-LAN 时:知情(企微转发)、队列(GitHub)、.md 拆件全程不断;唯归档原件延迟到回 LAN 同步(或直接用企微转发那份)。

## 二、六个设计决策点(CC design 逐条细化,Paul 审)

| # | 决策点 | 总线预判(默认方案) | 需 CC 核实/Paul 拍板 |
|---|--------|-------------------|---------------------|
| D1 | **队列回写机制** | Mac 直接 commit+push(bot 身份,message 约定 `bot(队列): 自动追行 #N`;push 前 pull --rebase,冲突重试 3 次,仍败则降级写本地 inbox.jsonl + 私信告警 Paul)——与编辑锁协议〇.7 兼容性需设计(bot 只 append 行,不整段改写) | 冲突策略 Paul 认可;锁协议是否对 bot 豁免或轻量适配 |
| D2 | **仓库凭据** | GitHub 细粒度 deploy token,只授本仓库、只 push 权限;存 Mac 钥匙串/`.env`(600 权限),不入任何文档 | 用 Paul 名下 token 还是建 bot 账号(建议后者,审计可辨) |
| D3 | **归档同步** | `7-外部文档` 保持 gitignore(敏感边界不变);Mac=收件真身,笔记本回 LAN 跑单向 rsync/robocopy 拉平(SSH 到 Mac);热路径=企微转发件。**禁止**把 Mac 仓库副本放 OneDrive(与 git 双同步会打架,既有教训) | 同步触发方式(手动一键/开机自动) |
| D4 | **常驻与自愈** | launchd LaunchAgent:`KeepAlive+RunAtLoad`(等价 Windows 计划任务+退避重启);节能设置关睡眠(`caffeinate`/设置);孤儿清理逻辑移植(pgrep/pkill 等价 Stop-OrphanServiceInstances);日志普通文件轮转(顺带告别 Windows transcript 中文重复 bug) | Mac 是否接 UPS/断电自启(BIOS 等价设置) |
| D5 | **切换与防双实例** | 先真实并测(Mac 起服务但白名单临时只含 Paul 自测)→ 验收通过→**原子切换**:停用笔记本 `ZhuopinAibotDevListener`(保留定义作冷备,文档注明手动启用条件)→ Mac 转正接白名单全量。**任何时刻只允许一个实例连企微**(07-19 双实例重复通报教训) | 切换窗口选低流量时段;冷备启用 SOP 一页 |
| D6 | **安全** | Mac 开 FileVault+登录口令;`.env`(BotID/Secret+群 webhook)600 权限;SSH 仅限 LAN;审计 jsonl 留 Mac+随归档同步带回笔记本备份 | IT 是否需要备案此设备用途 |

## 三、跨平台改造点(代码侧,预计很小)

核心 `aibot_service/` 为纯 Python(SDK/归档/追行/转发/哨兵),预期跨平台零改;需重建的是 **Windows 专属外壳**:`start-aibot-service-dev.ps1`→macOS shell 脚本、`run-hidden.vbs`→launchd 天然后台(不需要)、计划任务→plist、路径硬编码→Mac 路径 `.env` 化(`WECOM_AIBOT_QUEUE_PATH` 等指向 Mac 仓库副本)。

## 四、迁移步骤(CC 实施序)

1. Mac 环境:clone 仓库(独立路径,非 OneDrive)→ Python 环境 → `pip install -e` 平台底座 → `.env` 手工就位(不经 git)。
2. launchd 服务落位+D4 自愈项 → 白名单临时收窄自测(D5)。
3. E2E 真实验收:Paul 发测试件 → Mac 归档+追行 push GitHub+转发+群回执+哨兵沉默,五中五。
4. 原子切换(D5)→ 满 48h 观察(gap_alert 零异常)→ 笔记本任务停用转冷备,`wecom-service-home` worktree 退役清理(机房交接完成)。
5. 场景 CLAUDE.md/根 CLAUDE.md §5 企微段更新;回滚 SOP=停 Mac launchd+重启笔记本任务(一条命令各)。

## 五、不做清单

不碰 .51(IT 边界);不改归档/转发/门禁业务逻辑;不放宽两道门禁;`7-外部文档` 不入 git;二期才做"追行模板嵌 opener"(Dispatch 试点前置,见队列 #88 注)。
