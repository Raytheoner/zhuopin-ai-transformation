# 开场 Prompt —— 财务域场景落地专线

```

先读上下文恢复（按序）：
① CLAUDE.md 当前进度（§4 底座/ZpConnector、§5 工作分工、§7 红线：audit/L2/先mock再真实）

④ 1-转型规划/FI1-对接人首周收口单（合并）.md（收口-1~6 单一入口）
⑤ 1-转型规划/FI1-ERP-CSV导出需求（给IT与生产）.md（数据源）

【本 Task 定位】财务域场景落地专线，独立于"全景规划路线图跟踪"那条 Task。
本 Task 只管财务域（FI1 仓库对账、FI2 月结加速、后续 FI3-FI8）的：业务口径收口、就绪材料、
价值验收设计、治理/汇报——全部 .md。不回填全景排期表、不动 Phase1 接力文件。

【现状·FI1】内部对账 MVP 已合 master（CC，e5ead24，mock 30 测试全绿、审计链通），
停在真实验证前。临时口径 fi1-temp-2026-06-29 占位，等对接人定稿即替换、不改引擎。
节奏（双轨并行）：规则草案首周（约7月初）→ CC 据草案起/已起 propose → 定稿 7/31 → 8月开发 → 9月试点。

【首件事·协助对接人收口 FI1 业务口径】
对接人牵头、支撑团队分担。本 Task 协助把下列口径写清、整理成可交 CC 的需求：
  - 收口-1（🔴）：差异分类规则（损耗溢短/超损/来料短缺/管理差异判定边界）+ L2 阈值 → 草案首周

    实际投料取哪条 ERP 记录（领料过账 vs 发料单）—— 收口-3/4 要拉生产/IT
  - 收口-5：ERP 投料/产出 CSV 导出（跟 IT+生产，已有需求文档）
  - 收口-6：历史人工对账黄金样本（8/15）
口径定稿→交 CC 替换临时口径、补真实 golden、跑真实小样本。

【其余范围】FI2 三单匹配口径提前备料（mock 上立，11月接口通即上）；FI1/FI2 价值验收指标设计（D-4）。

- docx 默认不转，除非我明确要。
```
