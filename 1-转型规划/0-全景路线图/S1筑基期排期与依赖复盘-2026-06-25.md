## 三、三大核心阻塞点

### 阻塞 A：U9C ERP 接口（影响 SC2、FI1、FI2）

**现状**：7/1 已提交申请，IT 无反馈；当前判断可能无现成标准 MCP 可直接申请。SC8 的实战经验给出了参考路径：ZpConnector + U9C webapi（OAuth2 + `/U9C/api/BOM/Query`），外网已验证通。但 CommonEntity/库存/预测订单等接口外网仍是 404，走 LAN/VPN。

**阻塞逻辑**：
- SC2 需要 ERP 采购模块（PO 下达/到货/质检）
- FI1 需要 ERP 出入库记录 + SMT 投料数据
- FI2 需要 ERP 财务模块单据流

**应对行动**（两手准备）：
1. **7/15 前**：IT 给出"有无现成 MCP + 接口清单 + 就绪时间表"。SC8 路径 = 先申请 CommonEntity/Query 等批量接口的外网开放或 VPN 通道。
2. **若 8/1 仍无时间表**：授权 AIOps 启用**备选方案**——SC2/FI1 先用 CSV 文件导出（ERP 定期导出 → 平台加载）走通场景逻辑，不等接口阻塞开发节奏。FI2（11月）有更长缓冲，可等接口就绪。
3. 备选方案已有先例：SC1 初期即用 CSV 数据，后期切实时接口。
