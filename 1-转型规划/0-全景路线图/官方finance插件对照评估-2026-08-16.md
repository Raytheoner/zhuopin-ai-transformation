# 官方 finance 插件对照评估（2026-08-16）

## 〇、一句话结论

**财务 10 场景无一重复实现官方 skill；官方插件是 L2 级方法论知识层（纯 Markdown 模板＋判定标准），我们的 FI 场景是 U9C 数据管道＋确定性引擎＋L3/L4 自动化——不同层次，互补不竞争。** 重叠只出现在"分析报告类"场景（FI4/FI7）的方法论层，而这层恰可直接 fork 汉化；FI3 有一个时效性借力点（L4 会签底稿框架）。已裁定"U9C 原生覆盖、不建 AI"的财务月报/凭证领域，不因官方有 skill 而回头重建。

## 一、官方插件底细（源文件核对，非文章转述）

8 个 SKILL.md 实为 5 组能力：**reconciliation**（GL/银行/公司间对账＋差异三分类 timing/需调整/需调查＋账龄升级阈值）；**close-management**（月结 T+1~T+5 任务日历＋依赖图＋状态看板＋3 日加速月结前提清单）；**journal-entry×2**（凭证编制＋审批矩阵＋复核清单）；**variance-analysis**（价量/率构成分解＋重要性阈值框架＋叙事质量清单＋瀑布图方法）；**financial-statements**（三表生成，GAAP ASC 220/210/230）；**sox-testing＋audit-support**（SOX 404 控制测试：抽样方法与样本量表＋测试底稿模板＋证据有效性标准＋缺陷三级分类＋P2P/ITGC 等控制清单）。

定位判断（关键）：它**没有一行匹配引擎代码**，默认人工粘贴数据或接 Snowflake 类连接器，产出是底稿与分析文本。文章"节省 80%"是营销话术；"GAAP 需换企业会计准则、无国内 IM 连接器"两点属实。Apache-2.0，可自由 fork 定制。

安装：Cowork 端已装（本评估即逐文件读的已装源码）；CC 端两条命令——`claude plugin marketplace add anthropics/knowledge-work-plugins` → `claude plugin install finance@knowledge-work-plugins`。

## 二、逐场景对照判定

| 场景 | 官方覆盖 | 判定 |
|---|---|---|
| FI2 三单匹配（已建成，不动） | 仅在 SOX P2P 控制清单中作为"测试项"出现 | 无重复；不动正确 |
| FI3 付款校验（2026-11，部分 2026-10） | 无对应 skill；但 audit-support P2P 控制清单与 FI3-1/2/3 一一对应（三单匹配、重复付款防控、供应商主数据变更、付款审批 SoD） | 无重复；**借力点见 §三.1** |
| FI4 智能月结（2027-Q1） | **重叠最高**：close-management 日历/依赖图/看板；reconciliation 银行对账格式＋差异三分类（与 FI4 规划的"单据缺失/时间性差异/重复入账"根因分类几乎同构）＋账龄升级 | 方法论层整体可 fork |
| FI7 预算监控（2027-Q2） | variance-analysis 覆盖"月度偏差分析报告"半边：阈值框架、叙事模板、瀑布图、Budget vs Actual vs Forecast | 方法论层可 fork |
| FI1（暂缓）/FI5/FI6/FI8/FI9/FI10 | 基本无覆盖（FI9 高新认定纯中国监管零覆盖；FI8 可参考 small-business 插件 cash-flow-snapshot 方法论；FI10 NRV 仅一句带过） | 无重复 |

## 三、借力路径（按消费时点排序）

### 3.1 FI3 design 期（2026-10/11，唯一有时效压力的一条）

① 把 audit-support 的 **P2P 控制清单**当 FI3 openspec design 的对照校验清单（防漏项，零成本）；② 把 sox-testing 的**测试底稿模板**（测试步骤/证据有效性标准/缺陷三级分类）汉化后作为 FI3 **L4 晋级 Shao Peishen + CFO 会签的标准化证据框架**——会签材料目前无固定格式，这份是现成的，且证据标准（"口头确认不算、无日期文档不算、须可识别执行人"）与 IATF 可追溯口径同向。

### 3.2 FI4 启动前（2027-Q1）

fork close-management ＋ reconciliation 两个 SKILL.md，三处本地化：GAAP→企业会计准则；T+5 日历→卓品月结日历；escalation 阈值按我方 materiality 定。作为 FI4 规则层输入，省掉整段方法论设计。

### 3.3 FI7 启动前（2027-Q2）＋ 可提前小用

fork variance-analysis。其中**叙事质量清单**（禁止循环解释/必须量化/必须说 why/必须给展望）现在即可套用在 FI2 差异报告与月度价值记分牌上，零成本提升报告质量。

### 3.4 明确不引入

financial-statements 与 journal-entry——对应已裁定"U9C 原生覆盖、不建 AI 场景"的财务月报/凭证领域，去重决策依然成立；SOX 美式框架不整套照搬（非美股上市），只取控制测试方法论。
