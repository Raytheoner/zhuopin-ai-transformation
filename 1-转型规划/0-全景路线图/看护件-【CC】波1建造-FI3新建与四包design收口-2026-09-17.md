## 二bis · 业务总线本次给出的一条判据：FI10 §2.2「芯片 API 是不是同一项」

`fi10` §2.2 写明「判定前不得开始选型，否则可能选错标的」（队列 `#475`），并把判定交全景路线图线。**本件给出判定，CC 只落字、不重判**：

**判定 ＝ 不是同一项，是两项，被一个条目混着写了。** 取证（三处载体逐字）：

| 载体 | 原文 | 语义 |
|---|---|---|
| 前置总表 §一 O2 行 | 「**芯片供货 API** 选型 + 关键料号清单」 | 供货侧：LT 变更、停产、供应风险 |
| 实施计划 §外部依赖表 | 「**芯片市场价格 API** ｜ O2 芯片预警子功能（原 SC6）/FI10」 | 价格侧：市场价格波动 |
| 全景规划 §12月交付物段 | 「SC6（芯片预警）、O3（物流追踪）、**FI10（存货跌价，原 FI8）各依赖外部 API**」 | 只说「各依赖」，未说同一个 |

🔑 **O2 芯片预警要的是「这颗料还供不供得上」，FI10 存货跌价要的是「这颗料现在值多少钱」。** 前者是交期与库存信号，后者是价格曲线；**同一家供应商可能两样都卖，但它们是两个数据产品、两份合同、两套字段**。实施计划那一行把两者并成一条，是 2026-07 写表时的简写，不是判定结论。

⇒ **CC 落字动作**：`fi10` §2.2 打勾并写明「判定＝两项，依据＝本看护件 §三」；**选型仍不在本包**（属采购/IT，O2 侧的供货 API 选型另有排期）。🔴 **本条判定只解锁 FI10 的价格侧标的描述，不解锁任何采购动作。**
