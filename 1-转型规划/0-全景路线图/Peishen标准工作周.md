# Paul 标准工作周

> 一句话：**周一批计划，平时只做"发动、签收、拍板"三个动词，其余交给系统。**

## 一、周一早 · 批阅（约 20-30 分钟，唯一固定动作）

8:37 值周巡检自动产出《本周计划-日期.md》。Paul 只做三件事：

1. 调整 A 节任务优先级（砍不急的、提急的）；
2. 回答 B 节决策清单（每条一句话）；
3. 扫 C 节临期红线 + D 节异常警示。

批完即"计划先行"成立，本周不再需要 Paul 编排任务。

## 二、周中 · 三类碰触（每天累计 10-30 分钟，事件驱动）

**发动**：从《本周计划》A 节复制开场词开 session（一天一两条）。session 自行读队列认领、登记触碰区——Paul 不交代内容。
**签收与拍板**：专员回复到件 → 放 `7-外部文档/<部门>/`，说一句"已归位"（R6）；session 抛出的裁决点（每次 ≤5 个）一句话定；重大交付回"验"字触发收货验证。
**放行**：session 报"待 commit 批次"后，一句话交 CC 取活销行。

## 三、周中 · 线下（AI 不可替，VP 本职）

发专员跟进信、开批改会/校准会、对 IT/CFO/CEO 推前置与对齐、签字项（黄金重核/L2/晋档）。

## 四、月度与季度叠加

- **月初**：协同一页纸刷新（对总线说一句）。
- **月底**：价值记分牌 + 收专员一句话进展。
- **季度**：归档批量搬运（R3）、CLAUDE.md 进度段迁编年（R5）。
- **节点**：S 阶段收口前外部对抗性评审（S1≈2026-11 中旬）。

## 五、Paul 不再做的（出现即流程跑偏，值周巡检 D 节告警）

| 跑偏信号 | 应由谁承接 |
|---------|-----------|
| 转述 A 线结论给 B 线 / 截图搬运 CC 报告 | 队列（收工写、开工读） |
| 脑内防撞排程 / 追问"这个谁在做" | 队列触碰区 + 在办状态 |
| 拼开场词 / 写长交接 prompt | 《本周计划》A 节 + kickoff-prompt skill |
| 盯 commit 归属 / 同一 merge 多处发起 | 队列 §二 待 commit 批次（CC 独取） |
| 口径重梳期还有人在建旧口径 | 队列 §三 冻结标 |

## 六、值周巡检自检口径（每周执行）

巡检生成《本周计划》时，对照本文件检查上一周：① Paul 是否被迫做过 §五 表中任何一项（从队列/接力/会话痕迹判断）；② 固定动作是否漏拍（上周计划 B 节决策是否有未回答项遗留）；③ 有偏差 → 写入 D 节并给出机制修补建议；④ **§七 六步循环上周各步有无空转**（哪一步本周零产出、卡在哪个「以人的速度运行的环节」）。本文件内容变更须 Shao Peishen 拍板。

### 7.1 两条总线怎么配合（Shao Peishen 2026-09-08 问，答案落此）

| | 业务总线【Cowork】 | 环境总线【Cowork】 |
|---|---|---|
| 管什么 | 场景行 `[D:业]`、跟进信全生命周期（起草→待你审→发送四态）、grill 会话 opener、拆件报告消化与派生行、§三 冻结标、场景 `CLAUDE.md` 部署状态、发布第 8 步 | 机制行 `[D:机]`、工具／hook／sweep／skill、队列纪律（WIP／K2／退休制）、值周巡检章程、接力卡 Phase1、机制缺陷派单件 |
| 看护件 | 业务建造批（worktree 内建造含业务场景代码＝🟢） | 机制批（工具改动、合入、design 审＝多 🟡） |
| 只读不改 | 工具源码（缺陷 ⇒ 登 §一 `[D:机]`／§四，**不就地修**） | 场景代码与信件（需求 ⇒ 登 §一 `[D:业]`，**不代起草**） |
| 共享载体 | 两份队列一把锁 ／ 口径点台账（业务写点、机制建工具） ／ §四 决策台账 ／ LAN 收口批（任一线备件、CC 执行） | 同左 |

三条硬口径：① **两线只经队列行与派单件交接，不经聊天**——业务线发现机制缺陷 ⇒ 立行＋派单件，环境线建成 ⇒ 行内 ✅＋指针，对方开工三查自然读到；② **两线可同时开、也可只开一条**——另一条不在线时活停在队列行，不丢；③ **撞车只靠触碰区＋编辑锁**，两线都不得改对方在办行的触碰文件。

### 7.2 泳道看护随时可开（与 on/off-LAN 无关）

- **口令**：在任一 Cowork 总线会话说「**开启泳道看护**」（旧口令「offlan清池」等价）。Cowork 跑四查（LAN 探针／`--digest` 扫池／在跑批 `summary`／WIP 复算）→ 按触碰区排波（每批 ≤10、并行 4、错峰 90 s）→ 出看护件（§〇–§四＋§三bis）→ **他只粘一段**看护者开场词进 CC → 看护者 Task/Agent 扇出、各泳道 `isolation: worktree`。
- **LAN 只改变候选范围，不改变能否开批**：off-LAN ⇒ 依赖内网的项落「LAN 留步」清单，其余照跑；on-LAN ⇒ `.51` 项仍先 ⏭️ 转出，随后可经 `deploy-authorize`（三前置：探针 on／已有转出记录／他的授权原文）在同 session 续做（`#478`）。回内网说「我已回Lan」⇒ `zhuopin-lan-closeout` 串行清 LAN 留步。
- **档位**：🟢 自动做完（队列回灌／文档／只读取证／单测／worktree 内建造／openspec 起草）；🟡 `pause` 等他一字母（合入 master／改口径阈值／design 审／关他人行；**只认 Cowork 侧答复**）；⏭️ 转出不执行；🔴 只到可发送态即停（对外发送／L2／合规红线／ASIL C-D）。
- **并批约束**：新批候选须与在跑批触碰区零重叠（`summary --batch <在跑批>` 现取）；机制行受 WIP 22 上限、业务行不受；看护会话不修工具。
