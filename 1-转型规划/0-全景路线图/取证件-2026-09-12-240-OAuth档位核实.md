## 二、可达性判定：原始命令与返回（2026-09-12 18:43–18:45 本地，本机 off-LAN、经 TUN）

⑴ 登记回调域名 → 网关健康检查（**真实 HTTP 200，非 fake-ip 假阳性**：返回体是网关自己的 JSON）
```
$ curl -sS -i --max-time 15 "https://aiportal.equalitytec.com:8443/api/ping"
HTTP/1.1 200 OK
Server: nginx
Content-Type: application/json
{"service":"\u7edf\u4e00\u95e8\u6237\u7f51\u5173","status":"ok"}      ← "统一门户网关"
```
⑵ 根路径 → 未登录 302 到登录页（与 #162 archive 描述一致，证明打到的就是那台网关）
```
$ curl -sS -i --max-time 15 "https://aiportal.equalitytec.com:8443/"
HTTP/1.1 302 FOUND
Location: /portal/_sso/login?next=%2F
```
⑶ 登录页与 OAuth 起点（**决定性证据**）
```
$ curl -sS "https://aiportal.equalitytec.com:8443/portal/_sso/login?next=%2F"
<h3>统一门户登录</h3><a href="/portal/_sso/mock-login?next=%2F">⚠️ 开发/试点登录（非正式身份验证）</a>
        ← 只有 mock 登录链接，无「企业微信登录」（webapp.py L85-88：oauth_cfg is None 时不渲染）
$ curl -sS -i "https://aiportal.equalitytec.com:8443/portal/_sso/oauth/start?next=%2F"
HTTP/1.1 404 NOT FOUND                                              ← webapp.py L103-104「企微 OAuth 未配置」
```
⑷ 企微 OAuth 两个端点（用哑凭据探测，拿到企微业务错误码即证明端点可达）
```
$ curl -sS "https://qyapi.weixin.qq.com/cgi-bin/gettoken?corpid=dummy&corpsecret=dummy"
{"errcode":40013,"errmsg":"invalid corpid, hint: [...], from ip: 117.148.74.165, ..."}
$ curl -sS -o /dev/null -w "http_code=%{http_code}\n" "https://open.weixin.qq.com/connect/oauth2/authorize?appid=dummy&..."
http_code=301
```
⑸ 旁证：`.51` 内网直连本机不通（`curl http://192.168.100.51:8090/api/ping` → `(52) Empty reply`，TUN 吞包），与 opener「off-LAN」一致；`https://aiportal.equalitytec.com/`（443）→ `(35) TLS handshake failed`，即只开了 8443，与陈承登记的端口一致。
