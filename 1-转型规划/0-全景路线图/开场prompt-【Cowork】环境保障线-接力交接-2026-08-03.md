1. 滚动 `session接力-Phase1收口.md`；新发现当场登队列行（`--reserve` 取号）。
2. 列出全部新产出/修改文件清单 + 建议 commit message。
3. **登记 §二 批次（含「本批变更参数」一句）并立即触发 sweep**；本线不自行 commit。**触发后必核 `ahead` 与脏文件**。
4. session 过长主动提示转场，**并给单一可复制 opener**：转场回复里**必须有且只有一个 fenced 代码块**，块内第一行是【设置】行、其后是含完整相对路径的开场词，其余说明放块外。
   - **转场提议必须带可核验依据**（他的实际消息条数、本 session 落库的 commit 与批次、具体哪几块在占上下文），**禁止用自报工作量**（"跑了 N 轮""纠错 N 次"无人能交叉验证）。
   - **先压缩、后转场**：大块一次性证据一旦结论已上盘，原文即无保留价值。**上下文长 ≠ 该转场**；真正该触发的是质量信号（同一事实反复记错、自我纠错开始出现在刚写完的内容上）。
5. **会话末固定小节「需你定夺」**：编号 + **带字母标签选项** + 每项写清选项间实际差异与代价 + **标注默认项** + 临期置顶 + 并列悬置项；无则明写"本次无需你决策"。
   - 🔴 **两栏各归各位、双向都禁**（2026-08-03 补齐）：不得把纯状态混进「需你定夺」，**也不得把需他定夺的事塞进「状态同步（无需你答）」**。判据＝**凡出现"等你定／请你选／待你拍板"字样，一律属「需你定夺」**。
