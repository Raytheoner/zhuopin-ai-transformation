# 专线 opener 模板库

> 用法:选模板 → 填〔〕内变量 → 整段(含【设置】行)粘进对应桌。**☐=Cowork 桌(无需选择,天然☐);☑=CC 桌勾 worktree。** 发送类动作模板自带幂等自检,重复发不会发生。

## 一、回件拆件(通用,四域同构)——最高频

```
【设置】分支：master ｜ worktree：☐（〔域〕专线只编 .md）
读 CLAUDE.md + 跨桌任务队列 #〔行号,如 80-82〕 + 〔域〕域接力最新节，拆件〔专员名〕〔日期〕回件（7-外部文档/〔部门〕/ 对应文件）：①逐件核实内容按既定预案/口径落档回灌（有预案照落,无预案先 triage 分类：bug→登 CC 待领行 / 口径→三步法批改件 / 功能→圈选排期）；②特例提示：〔如"对照表复选框为死字符,作答是文字形式,逐项人读"；无则删〕；③相关行一并销行。判定是否触发全景重组（初判无）。收工登记 §二批次交 CC。
```

域接力文件对照:采购=`session接力-采购域场景落地.md`｜财务=`session接力-财务域场景落地.md`｜质量=`session接力-质量域场景落地.md`｜总线=`session接力-Phase1收口.md`。

## 二、CC 落库(取 §二 批次)

```
【设置】分支：master ｜ worktree：☐
读跨桌任务队列 §二，取 〔批次名,如 B-0723XX〕 批次 commit+push+收工重跑台账。
```

多批可并列写；勿点 Create PR,直推 master。

## 三、CC 建造(新活,独立 worktree)

```
【设置】分支：master ｜ worktree：☑（〔任务短名〕，新 worktree，收工自删）
读 CLAUDE.md + 跨桌任务队列 #〔行号〕 + 〔输入文件指针〕，认领 #〔行号〕：〔任务要点,照抄队列行期望产出〕。走 openspec（涉新 design 停下等 Paul 审）；全量回归零回归、黄金基准不漂移。收工登记 §二 + push + 重跑台账；推送确认 ahead=0 后 cd 回主工作区自删本 worktree（删不掉则收工报告列"待清 worktree"）。
```
