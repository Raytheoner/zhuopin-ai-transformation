# 提权代码块 · 队列 #199②＋#193 次要项

## 背景

队列 #199②（`ZhuopinDecisionReminderDaily` 补 `-StartWhenAvailable`）与 #193 次要项
（`ZhuopinAibotDevListener` 补 `AtStartup` 触发器 + `RestartCount`/`RestartInterval`
二层兜底）均需修改**在跑计划任务的实际设置**，本机非提权 PowerShell 实测均报
`拒绝访问`（Access denied）。已按拍板 (a) 的执行方式——CC 不要求 Shao Peishen 自己
拼参数，整理成下方单个自包含代码块，含全部现有设置的保留重建（不会丢失
`ExecutionTimeLimit`/`Hidden`/`Priority` 等既有值）。

顺带在同一次提权窗口内启用 Task Scheduler 操作日志（供未来同类
`0x800710E0` 式间歇性失败问题追查——注意**不能回溯**本次已发生的 08-01 那次，
只对启用之后的新失败有效）。

## 执行方式

以**管理员身份**打开 PowerShell（右键 → 以管理员身份运行），整段粘贴执行：

```powershell
# 队列 #199②+#193次要项：需管理员权限
$settings1 = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Minutes 10) `
    -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Set-ScheduledTask -TaskName 'ZhuopinDecisionReminderDaily' -Settings $settings1

$task2 = Get-ScheduledTask -TaskName 'ZhuopinAibotDevListener'
$newTriggers = @($task2.Triggers) + @(New-ScheduledTaskTrigger -AtStartup)
$settings2 = New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan -Hours 72) -Hidden `
    -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries `
    -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1) -MultipleInstances IgnoreNew
Set-ScheduledTask -TaskName 'ZhuopinAibotDevListener' -Trigger $newTriggers -Settings $settings2

wevtutil sl "Microsoft-Windows-TaskScheduler/Operational" /e:true

Get-ScheduledTask -TaskName 'ZhuopinCommitSweep','ZhuopinAibotDevListener','ZhuopinDecisionReminderDaily' |
  ForEach-Object {
    [PSCustomObject]@{
      Task = $_.TaskName
      StartWhenAvailable = $_.Settings.StartWhenAvailable
      RestartCount = $_.Settings.RestartCount
      Triggers = (($_.Triggers | ForEach-Object { $_.CimClass.CimClassName }) -join ',')
    }
  } | Format-Table -AutoSize
```
