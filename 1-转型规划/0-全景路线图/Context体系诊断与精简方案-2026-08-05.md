规则总量 ＝ CLAUDE.md §5（23KB）＋ 队列协议〇（7.8KB）≈ **11k token**，占 145k 的 **7.5%**。
**其余 92.5% 是历史记录与调度数据。**

⇒ **规则执行力打折不是规则写得不好，是注意力被稀释了 13 倍。**

**本 session 自身即活证据**（2026-08-05 单次会话内）：

## 三、memory 层实证（2026-08-05，推翻既有结论后重测）

| 检查项 | 结果 |

| Write 工具写 `spaces/*/memory/_writetest_20260805.md` | 报 **File created successfully** |
| PowerShell `Test-Path` 反查 | **False**，目录内容零变化 |
| 注入 session 上下文的 MEMORY.md 索引所列 6 个文件 | **全盘（AppData\Roaming\Claude 递归）零命中** |
| MEMORY.md 文件本身 | **全盘不存在** |
| 目录内真实文件 | **2 个**：`feedback_prompt_must_label_target_app.md`(07-27)、`project_harvest_progress.md`(06-11)，**均不在索引里** |
| space 目录数 | 1 个（`88cb0587-…`），子项 2 |

**结论**：
1. **写入通道已断**，断裂点在 Cowork 内部——那 2 个文件证明**同一路径历史上写得进**（06-11／07-27），故非路径错误；
2. **索引与磁盘双向不一致**：索引指向的文件不存在，存在的文件不在索引里；
3. **半死状态比明确废弃更危险**——它偶尔会被信，且注入上下文的索引本身就是误导源。

⇒ **「修好它」在当前环境下无法由本项目侧完成。** 两条可行替代见 §五决策 2。
